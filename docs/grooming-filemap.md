## 🔗 2) ไฟล์รวมทุกหมวด (shared · สร้างจาก redesign md ทั้งหมด)

| ไฟล์ | คืออะไร | หมายเหตุ |
|---|---|---|
| `docs/branches-clean.md` | **"md เฉพาะหมวด"** = กิ่งล้วน (ชื่อไทย+อังกฤษ+นิยาม) **ไม่มีคำ ไม่มีความเห็น** | กิ่ง = หมวด · เฉพาะหมวด = เฉพาะกิ่ง |
| `docs/branches-data.md` | กิ่ง **+ คำ** (ไม่มีความเห็น) ฉบับอ่านทวน | มี 🔗 โยงข้ามหมวด · 🚚 ยกออก |
| `docs/branches-data.json` | ข้อมูลเต็ม (categories+branches+words+cross_links+moved_out) — **ทุกคำมีช่อง `meaning`** | แมปกับตาราง `wb_` |
| **ตัวสร้าง:** `scripts/gen_branches.py` | อ่าน cat1-7·8·10·11 redesign.md → เขียน 3 ไฟล์บนพร้อมกัน | `python3 scripts/gen_branches.py` |

> 💾 **กฎความหมาย (พี่กันสั่ง 25 ก.ค. 2569 — กันความหมายหาย):** คำในต้นฉบับส่วนใหญ่มีความหมายอยู่แล้วในคลังจริง (Supabase `wb_words.meaning`) ไม่ต้องพิมพ์ซ้ำ · แต่ **คำใหม่ที่ยังไม่มีในคลัง (➕ เพิ่มใหม่ · คำที่ยังไม่มี meaning ในคลัง) ต้องเขียนความหมายกำกับที่ตัวคำเองเสมอ** รูปแบบ **`คำ (ความหมาย)`** (เว้นวรรคก่อนวงเล็บ — คนละแบบกับ `_(...)_` ตัวเอียงที่ใช้บอกกิ่งโยง/หลายกิ่ง) → `gen_branches.py` จะดึงใส่ช่อง `"meaning"` ในไฟล์กิ่งรวมให้อัตโนมัติ **ห้ามเขียนความหมายไว้แค่ในบรรทัด 🗨 หมายเหตุเท่านั้น เพราะสคริปต์ข้ามบรรทัด 🗨 ทั้งบรรทัด ความหมายจะหายไปเงียบๆ**
> 🔴 **เคยพลาดจริง 25 ก.ค.:** คำ "สำทับ" (หมวด 3 · คำใหม่ ยังไม่มีในคลัง) เขียนความหมาย "(กำชับ/บอกซ้ำ/ย้ำ)" ไว้ แต่ตัวสคริปต์เดิมตัดวงเล็บท้ายคำทิ้งไปเงียบๆ ไม่เก็บที่ไหนเลย → **แก้แล้ว:** `gen_branches.py` จับ `คำ (ความหมาย)` ใส่ช่อง `meaning` ในทุกไฟล์กิ่งรวม + ไล่แก้คำเดิมที่เคยมีปัญหาแบบนี้ครบแล้ว (ตรวจสอบ 25 ก.ค. ไม่มีคำไหนหลุดอีก)
> ⚠️ **บั๊กเสริม (พบพร้อมกัน):** อย่าเขียนคำว่า **"รอเก็บคำ"** เป็นบรรทัดคำแยกต่างหาก (สคริปต์จะอ่านเป็นคำจริง) — ต้องอยู่ **ในบรรทัด 🗨 หมายเหตุเท่านั้น** เหมือนหมวด 1/2/10 (ตัวสคริปต์มีตัวกันไว้อีกชั้นแล้ว แต่ควรเขียนให้ถูกตั้งแต่ต้น)

## ⏳ 2.5) ลำดับเวลา — **md ก่อน · ที่เหลือรอพี่กันตรวจไฟนอล** (พี่กันสั่ง 25 ก.ค. 2569)
> 🛑 **ระหว่างเกลาหมวด (ยังไม่ไฟนอล) แก้แค่ `catN-redesign.md` แล้วส่งให้พี่กันอ่าน — ห้ามทำ HTML / ห้ามรัน `gen_branches.py` ล่วงหน้า**
> เหตุผล: พี่กันต้องอ่าน md ก่อน อาจสั่งแก้อีกหลายรอบ · ทำ HTML/ไฟล์รวมไว้ก่อน = เสียเปล่า + ต้องทำซ้ำทุกรอบ
> ✅ **ทำ HTML + ไฟล์รวม (branches-*) ตอนพี่กันบอกว่าไฟนอลแล้วเท่านั้น** — แล้วทำรวดเดียวจบตาม flow ข้อ 3
> 🔴 เคยพลาดจริง 25 ก.ค.: เกลาหมวด 2 เสร็จแล้วรีบสร้าง HTML ทันที 2 รอบ ทั้งที่พี่กันยังไม่ได้อ่าน md เลย → พี่กันท้วง _"อย่าเพิ่งทำ html โว้ย ยังไม่ตรวจทานเลย"_

## 🌊 3) FLOW กันลืม — แก้กิ่ง ๑ จุด ต้องแตะไฟล์อะไรบ้าง

เมื่อแก้ **ชื่อไทย / ชื่ออังกฤษ / นิยาม / คำ** ของกิ่งใด ๆ:

1. **แก้ `docs/catN-redesign.md`** (ต้นฉบับ — แก้ที่นี่ก่อนเสมอ)
2. **ซิงก์ `docs/catN-redesign.html`:**
   - หมวด **5·6·8·11** → `python3 scripts/gen_catN_html.py`
   - หมวด **1·2·3·4·10** → **แก้มือในไฟล์ .html** (แทนข้อความไทยให้ตรง md)
3. **รัน `python3 scripts/gen_branches.py`** → อัปเดต `branches-clean.md` + `branches-data.md` + `branches-data.json` พร้อมกันอัตโนมัติ
4. **(ถ้าพี่กันจะอ่าน)** ส่ง md ให้พี่กัน (SendUserFile) + republish Artifact HTML (ลิงก์เดิม)

> ⚠️ **ที่เคยพลาด (25 ก.ค.):** แก้ md redesign แล้วลืมทำข้อ 2-3 → HTML + ไฟล์รวมค้างเป็นของเก่า ไม่ตรงกับ md
