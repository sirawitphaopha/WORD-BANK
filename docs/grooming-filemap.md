## 🌊 3) FLOW กันลืม — แก้กิ่ง ๑ จุด ต้องแตะไฟล์อะไรบ้าง

เมื่อแก้ **ชื่อไทย / ชื่ออังกฤษ / นิยาม / คำ** ของกิ่งใด ๆ:

1. **แก้ `docs/catN-redesign.md`** (ต้นฉบับ — แก้ที่นี่ก่อนเสมอ)
2. **ซิงก์ `docs/catN-redesign.html`:**
   - หมวด **5·6·8·11** → `python3 scripts/gen_catN_html.py`
   - หมวด **1·2·3·4·10** → **แก้มือในไฟล์ .html** (แทนข้อความไทยให้ตรง md)
3. **รัน `python3 scripts/gen_branches.py`** → อัปเดต `branches-clean.md` + `branches-data.md` + `branches-data.json` พร้อมกันอัตโนมัติ
4. **(ถ้าพี่กันจะอ่าน)** ส่ง md ให้พี่กัน (SendUserFile) + republish Artifact HTML (ลิงก์เดิม)

> ⚠️ **ที่เคยพลาด (25 ก.ค.):** แก้ md redesign แล้วลืมทำข้อ 2-3 → HTML + ไฟล์รวมค้างเป็นของเก่า ไม่ตรงกับ md
