## 🚨 กฎที่ห้ามลืมเด็ดขาด (อ่านก่อนแตะคลังคำทุกครั้ง)

### 1. คลังเก่ากับคลังใหม่ **ห้ามรวมกัน** จนกว่าพี่กันจะสั่ง
พี่กันสั่ง 26 ก.ค.: _"อย่าลืมว่า คลังเก่า กับคลังใหม่ ห้ามรวมกันตอนนี้ จนกว่าเราจะบอก"_

| คลัง | จำนวน | ไฟล์ผลลัพธ์ |
|---|---|---|
| คลังเดิม | 1,060 คำ (2,549 เส้นเชื่อมคำ-กิ่ง) | `docs/oldwords-branches.json` |
| คลังชุดใหม่ (นิยายสืบสวน) | 1,891 ชิ้น | `docs/newwords-branches.json` |

**สองไฟล์นี้แยกกันเด็ดขาด** ห้ามเอามาต่อกันเองไม่ว่าด้วยเหตุผลใด

### 2. ตอนรวม 2 คลัง — คำซ้ำ **ห้ามลบ** ต้องโยงตามระบบใยแมงมุม
พี่กันสั่ง 26 ก.ค.: _"อย่าลืมว่าตอนที่รวม 2 คลัง มันจะมีคำซ้ำเยอะมาก ห้ามลบ แต่ต้องโยงตามระบบใยแมงมุม"_

- 🔗 **คำที่มีทั้ง 2 คลังตอนนี้ = 137 คำ** (ตัวเลขนี้โตขึ้นเรื่อย ๆ ตามคำที่เพิ่ม — เดิม 67 คำ)
- คำซ้ำ **ไม่ใช่ของเสีย** แต่คือ **คำเดียวกันที่เจอในนิยายคนละเรื่อง**
- วิธีที่ถูก = **คำหนึ่งแถว โยงไปหลายเรื่อง หลายวลีแม่ หลายกิ่ง** ไม่ใช่เก็บ 2 แถวหรือลบทิ้งอันหนึ่ง
- ต้องไม่ทำกิ่งหรือความหมายของฝั่งไหนหาย — **รวมกัน ไม่ใช่ให้ใครชนะ**

### 3. ทำงานเสร็จ = สร้าง md รายงาน + ส่งให้พี่กันตรวจทุกครั้ง
พี่กันสั่ง 26 ก.ค.: _"สร้าง md เป็นรายงานทุกครั้ง และส่งมาให้ตรวจทุกครั้ง นี่คือกฎ"_

เช็คลิสต์ที่ต้องมีครบทุกรอบ ห้ามข้ามข้อไหน
1. **md สรุปผล** — คำ/กิ่งที่เปลี่ยน แยกตามหมวด อ่านรู้เรื่องโดยไม่ต้องเปิดไฟล์อื่น
2. **HTML คู่กับ md** + ลิงก์ให้อ่านบนมือถือ
3. **JSON พร้อมขึ้นฐานข้อมูล** — โครงสร้างตรงกับคลังอีกก้อนเสมอ
4. **ฉบับสำรองของงานที่พี่กันลงแรงเอง** — ต้องลงเรพ ห้ามอยู่แต่ในเครื่องมือ
5. **ส่งไฟล์ให้พี่กันจริง ๆ** ไม่ใช่แค่บอกว่ามีไฟล์

### 4. ห้ามลบ/แก้/แตกคำต้นฉบับโดยไม่ถาม
แตกคำได้แค่ **เพิ่มคำใหม่แยกออกมา** วลีเดิมต้องอยู่ครบเสมอ
ยกเว้นกรณีที่พี่กันบอกเองว่าพิมพ์ผิด หรือระบบ import มัดมาผิด

### ง3 · กฎที่เจ้าของเคาะแล้ว 27 ก.ค. — ทำไปแล้ว 4 ข้อ
- [x] **เก็บความหมาย 100% ทุกคำ** → **คำสั่ง AI ฉบับที่ ๑๐** เลิกกฎ "ตีความทางเดียวใส่ null ได้"
      เหตุผลเจ้าของ: _"อุตส่าห์คิดความหมายแล้ว แต่ไม่เอา นี่มันเปลืองเงินโดยเปล่าประโยชน์"_
- [x] **ให้ AI เช็คว่าคำนั้นมีอยู่จริงในภาษาไทยไหม** → กฎข้อ 1ก ใหม่ในฉบับที่ ๑๐
      สงสัย = คงข้อความไว้ + ใส่หมายเหตุ `⚠ ไม่แน่ใจว่ามีคำว่า X ในภาษาไทย · น่าจะเป็น Y`
      **บังคับให้เสนอคำที่คิดว่าใช่เสมอ** เพราะเตือนเฉย ๆ ไม่ช่วยอะไร
- [x] **รายงานใส่เลขชั้นในวงเล็บ** → `ธรรมชาติและสภาพอากาศ(1)/พืชพรรณ(2)/ป่าและหมู่ไม้หนาทึบ(3)`
- [x] **เขียนศัพท์ชั้นกิ่งลงเว็บ** → หน้าเกี่ยวกับ มีบล็อก "กิ่งมีกี่ชั้น — เรียกชั้นไหนว่าอะไร"
      ผังไล่ หมวด → กิ่งหลัก(1) → กิ่งย่อย(2) → กิ่งแขนง(3) → คำ พร้อมตัวอย่างจริงและลูกศรเชื่อม
- [ ] 🔴 **ยังไม่ได้ทดสอบคำสั่งฉบับที่ ๑๐ กับโมเดลจริง** (คลาวด์ไม่มีกุญแจ)
      ต้องวัด: ความหมายขึ้นเป็น 100% จริงไหม · ต้นทุนเพิ่มเท่าไหร่ · ติดธงคำที่ไม่มีจริงได้ไหม

### ง4 · กฎชั้นกิ่ง (เจ้าของอธิบายเอง 27 ก.ค.)
🔑 **คำจะลงไปอยู่ชั้นลึกที่สุด "ของสายกิ่งนั้น" เสมอ — ไม่ใช่ต้องถึงชั้น 3 ทุกอัน**
- กิ่งหลักแตกถึงกิ่งแขนง → คำต้องลงถึงกิ่งแขนง
- กิ่งหลักแตกแค่กิ่งย่อย → คำลงถึงกิ่งย่อย
- กิ่งหลักไม่แตกอะไรเลย → คำอยู่ที่กิ่งหลักได้ เพราะนั่นคือชั้นลึกสุดของสายนั้น
- **คำค้างกลางทาง = ยังไม่มีกิ่งที่เหมาะให้ลง → ต้องซอยกิ่งเพิ่ม**
- [ ] ตอนนี้มี **26 เส้นเชื่อมใน 9 กิ่ง** ที่ค้างอยู่ ส่วนใหญ่กิ่งลูกที่มีไม่ตรงกับคำ (เช่น `ทะมึน` ค้างที่ "อารมณ์และความรู้สึกของสถานที่" ที่มีลูกแค่ "ความโอ่อ่าและความโทรม")
      🔵 **เจ้าของสั่งให้รอทำตอนรวม 2 คลัง** แล้วค่อยประเมินกิ่งที่คำกระจุกเยอะพร้อมกันทีเดียว
