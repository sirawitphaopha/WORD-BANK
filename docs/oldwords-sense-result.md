# ผลการทดลอง M2 — ให้ผู้ช่วยตัดสินคำโดยไม่เห็นวลีตั้งต้น

> สร้างอัตโนมัติจาก `scripts/gen_sense_result.py` · อย่าแก้มือ

## ๑ · ทำอะไร

พี่กันจับได้จากคำว่า **`เสียว`** ว่าคำที่สกัดออกมาถูกยัดกิ่งเดียวกับวลีตั้งต้น
รอบนี้จึงให้ผู้ช่วย **เห็นแค่ตัวคำล้วน ๆ** ไม่เห็นวลีตั้งต้น ไม่เห็นกิ่งเดิม แล้วให้ตัดสินใหม่ทั้งหมด

| | |
|---|---|
| คำที่ทบทวน | 394 คำ |
| คำที่ตีความได้หลายทาง | **122 คำ (31%)** |
| กิ่งที่เพิ่ม | **488 เส้น** |
| กิ่งที่ถอน | 4 เส้น |
| คำที่ได้ความหมายใหม่ | **72 คำ** |

## ๒ · ผลที่สำคัญที่สุด — M2 ใช้ "เพิ่ม" ได้ แต่ใช้ "ถอน" ไม่ได้

ผู้ช่วยเสนอให้ถอนกิ่งเดิมออก **88 เส้น** แต่แคลร์ตรวจเองแล้ว **ไม่รับ 84 เส้น**

**เหตุผล** — ผู้ช่วยไม่เห็นวลีตั้งต้น จึงมองไม่เห็นว่ากิ่งเดิมมีที่มาจากไหน
แต่กิ่งเดิมมาจาก**บริบทที่คำนั้นเจอจริง** จึงถูกต้องในตัวมันเอง

| คำ | วลีตั้งต้น | กิ่งที่ผู้ช่วยจะถอน |
|---|---|---|
| **กำยำ** | ร่างกำยำ | ร่างกายสดชื่นและแข็งแรง |
| **จิ๊** | ทำเสียงจิ๊ในปาก | เสียงจากปากและร่างกาย |
| **ชุ่ม** | ชุ่มไปด้วยเหงื่อ | เหงื่อและอุณหภูมิ |
| **ซู่ซ่า** | ส่งเสียงซู่ซ่า | เสียงเสียดสีและขูดถู |
| **ทะมึน** | เงาดำทะมึน | เงา |
| **ปรก** | หนวดเคราปรกหน้ารุงรัง | หนวดและเครา |
| **ผอมเรียว** | ใบหน้าผอมเรียวยับย่น | ใบหน้าซีดเซียวและทรุดโทรม |
| **เลือดเย็น** | โหดเหี้ยมเลือดเย็นน่าเกลียดน่ากลัว | เย็นชาไร้ความรู้สึก |
| **เสียว** | เสียวสันหลังวาบด้วยความหวาดกลัว | หวาดกลัวและขวัญผวา |
| **แก๊ก** | เสียงดัง แก๊ก | เสียงกระทบและแตกหัก |

🔑 **ข้อสรุปที่เอาไปใช้ต่อได้** — การปิดวลีตั้งต้นทำให้เห็นความหมายที่บริบทเคยบัง (ดีมาก)
แต่ก็ทำให้มองไม่เห็นเหตุผลของกิ่งเดิมด้วย · **จึงควรใช้ M2 เพื่อเพิ่มกิ่ง ไม่ใช่แทนที่กิ่ง**
ตรงกับกฎเหล็กของคลังที่มีอยู่แล้ว: *เพิ่มได้ ลดไม่ได้* และ *คำที่สื่อได้หลายกิ่ง ให้ติดหลายกิ่ง ไม่ใช่ย้าย*

## ๓ · กิ่งที่ถอนจริง 4 เส้น (ปลอดภัย)

> ถอนเฉพาะกรณี **ถอนกิ่งแม่ทั้งที่ยังเก็บกิ่งลูกไว้** = ละเอียดขึ้น ไม่มีข้อมูลหาย

| คำ | กิ่งแม่ที่ถอน | กิ่งลูกที่เหลือ |

| ชันเข่า | ท่าทางและภาพรวมร่างกาย / ท่านั่งและท่าเฉพาะจุด | การนั่งพักและทิ้งตัว · การห่อตัวและป้องกันตัว |

| ส่องสว่าง | แสงและเงา / แสง | แสงสว่าง |
| แมกไม้ | ธรรมชาติและสภาพอากาศ / พืชพรรณ | ป่าและหมู่ไม้หนาทึบ · ความเขียวชอุ่มและการไหวของใบไม้ |

## ๕ · คำที่ตีความได้หลายทาง — เห็นครบทุกความหมาย

> นี่คือหัวใจของรอบนี้ · เดิมคำพวกนี้ถูกจัดตามความหมายเดียวที่วลีตั้งต้นใช้

- **เสียว** — รู้สึกแปลบวาบที่ผิวหรืออวัยวะ เช่น เสียวฟัน เสียวแปลบ · รู้สึกหวาดเสียวระทึกเมื่อเห็นสิ่งล่อแหลม · รู้สึกเสียวซ่านเชิงกามารมณ์ · รู้สึกวาบขึ้นในใจเพราะกลัวหรือใจหาย
- **กระชับ** — จับหรือรัดให้แน่นขึ้น · สั้นได้ใจความไม่เยิ่นเย้อ · พอดีตัวไม่หลวมโพรก
- **กระเพื่อม** — ผิวของเหลวไหวเป็นระลอก · สิ่งของหรือร่างกายไหวขึ้นลงเป็นจังหวะ · อารมณ์หรือสถานการณ์ที่ไหวตัวขึ้นมา
- **ขนลุก** — ขนตั้งชันเพราะกลัวหรือสยอง · ขนตั้งชันเพราะความเย็นหรือสัมผัสบนผิว · ขนตั้งชันเพราะตื้นตันหรือประทับใจ
- **คมกริบ** — มีคมมากจนบาดได้ทันที · สายตาหรือคำพูดที่แหลมคมเฉียบขาด · ความคิดที่เฉียบแหลมรู้ทัน
- **ครวญคราง** — ครางเพราะเจ็บปวดทรมาน · ครางเพราะความเสียวซ่านหรือสุขทางกาย · ครางรำพันด้วยความเศร้า
- **คลอ** — น้ำตาเอ่อขังอยู่ที่ขอบตา · ร้องหรือเล่นเสียงประสานไปกับอีกเสียง · อยู่เคียงข้างไปด้วยกันตลอด
- **คำราม** — เสียงขู่ต่ำในลำคอของสัตว์ · คนเปล่งเสียงต่ำขู่ด้วยความโกรธ · เสียงกระหึ่มต่ำของฟ้าหรือเครื่องยนต์
- **นุ่มนวล** — ท่าทีอ่อนโยนไม่แข็งกระด้าง · เคลื่อนไหวลื่นไหลไม่กระชาก · สัมผัสหรือน้ำเสียงที่นุ่ม
