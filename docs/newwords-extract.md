# คำงามที่สกัดได้จากคลังคำชุดใหม่ ๑,๓๒๙ วลี

> อัปเดต 25 ก.ค. 2569 (รอบ ๒) · **ยังไม่แตะไฟล์คลัง** — รอเลือกคำก่อน
> 🖱 **มีเครื่องมือกดเลือกแล้ว: `docs/newwords-picker.html`** — เปิดแล้วกดเลือกคำได้เลย มีช่องสกัดเองทุกวลี ระบบจำที่เลือกไว้ให้ · ไฟล์ .md นี้ไว้อ่านทวน/ส่งต่อ

## ที่มาของไฟล์นี้

คลังคำชุดใหม่ตอนนี้ยังเป็น **"วลีตั้งต้น"** ล้วน ๆ — ยังไม่ได้ผ่านขั้นตอนที่ระบบในเว็บทำให้ตอนกดจัดคำ
คือ **การสกัดคำงามที่ซ่อนอยู่ในวลียาว ออกมาเป็นคำใหม่แยกต่างหาก** (กฎข้อ ๓ และ ๓ข ของ `lib/prompt.js`)

ตัวอย่างให้เห็นภาพ — วลี `เหงื่อเย็นเยียบพรั่งพรูจากแผ่นหลัง` ตอนนี้นับเป็น ๑ คำ เข้าได้หมวดเดียว
พอสกัดแล้วได้ `เย็นเยียบ` เพิ่มมาอีกคำ กระจายไปได้อีกหมวด

🎯 **เป้าหมายปลายทาง:** คำที่สกัดได้ไม่ใช่แค่ "คำเพิ่ม" แต่เป็น **วัตถุดิบรอบใหม่สำหรับหาหมวด/กิ่งที่ยังมองไม่เห็น**
— รอบก่อนสแกนจากวลีตั้งต้นล้วน ๆ ได้ข้อเสนอ ๔๘ กิ่ง · รอบหน้าสแกนใหม่พร้อมคำที่สกัดได้ อาจได้มากกว่านั้น

🔗 **ทุกคำที่สกัดได้ผูกกับ "วลีตั้งต้น" เสมอ** — เพราะเว็บเก็บช่องนี้จริง (`source` ในตาราง `wb_review` และ `wb_words`)
ทั้งในตารางด้านล่างและในไฟล์ที่ส่งออกจากเครื่องมือ ทุกคำจะมีวลีตั้งต้นกำกับไว้เสมอ ไม่มีคำไหนหลุดออกมาลอย ๆ

## วิธีทำ

| ขั้น | ทำอะไร |
|---|---|
| ๑ | เอเจนต์ ๔ ตัว แบ่งอ่านคนละ ~๓๓๒ บรรทัด · ทุกตัวได้กฎจาก `lib/prompt.js` ฉบับจริง + ไฟล์คลังเต็มไว้เช็คคำซ้ำ |
| ๒ | รวมผล ๔ ตัว ตัดคำซ้ำระหว่างตัว → เหลือ **๕๓๓ คำไม่ซ้ำ** |
| ๓ | ตรวจซ้ำเองด้วยเครื่อง ๓ ด่าน (ดูหัวข้อ "การตรวจสอบ" ท้ายไฟล์) |
| ๔ | จัดกลุ่มตามหมวดที่น่าจะเข้า แล้วเรียงเลข ๑–๕๓๓ |
| ๕ | สร้างเครื่องมือกดเลือก `docs/newwords-picker.html` |

**นิยาม "คำงาม" ที่ใช้ตัดสิน** (ยกมาจาก `lib/prompt.js` ข้อ ๓ข) = คำที่เปลี่ยน *ข้อมูล* ให้เป็น *ประสบการณ์* ของคนอ่าน · ตัดสินที่หน้าที่ ไม่ใช่ความหรูหรา
(ก) เปลี่ยนข้อมูลเป็นภาพจำ ปลุกประสาทสัมผัส · (ข) แสดงความรู้สึกผ่านร่างกาย · (ค) จับเฉดอารมณ์ได้ตรงจุด · (ง) คุมจังหวะและน้ำหนักของฉาก

🔑 **ก้ำกึ่ง = สกัดไว้ก่อน** (prompt สั่งไว้ตรง ๆ ว่าให้ผู้ใช้เป็นคนตัดสินและลบเอง) → ในลิสต์นี้จึงมีคำที่อาจไม่เอาปนอยู่ ตั้งใจให้คัดออกเอง

🚨 **ทุกข้อคือ "เพิ่มคำใหม่" ไม่ใช่แทนที่** — วลีต้นทางยังอยู่ในคลังครบทุกวลี ไม่มีการลบหรือดัดแปลง

🌿 **หนึ่งวลีแตกได้หลายคำ** — หลายวลีในลิสต์นี้จึงมีคำเสนอ ๒–๕ คำ และในเครื่องมือก็เพิ่มเองได้ไม่จำกัดต่อวลี

## ข · เรื่องที่แก้ไปแล้วรอบนี้

| เรื่อง | บรรทัด | เดิม | แก้เป็น | ที่มา |
|---|---|---|---|---|
| แยกวลีที่ติดกัน | ๓๐๗ | `มืดตึดตื๋อควักนาฬิกาเรือนโต` | แยกเป็น ๒ บรรทัด: `มืดตึดตื๋อ` + `ควักนาฬิกาเรือนโต` | เจ้าของจับได้เอง |

| กดเลือกคำ | แตะที่คำเพื่อเลือก แตะซ้ำเพื่อยกเลิก · เห็นทั้ง ๕๓๓ คำที่ระบบเสนอ |
| สกัดเอง | ทุกวลีมีช่องพิมพ์ · พิมพ์แล้วกด Enter · **หนึ่งวลีเพิ่มได้หลายคำ** |
| เตือนเมื่อคำไม่อยู่ในวลี | คำที่พิมพ์เองแล้วไม่ตรงกับข้อความในวลีตั้งต้น จะเปลี่ยนเป็นสีทองเตือนไว้ (ยังเก็บให้ ไม่บล็อก) |
| ดูได้ทั้ง ๑,๓๒๙ วลี | ตัวกรอง "ทุกวลี" เปิดดูวลีที่ระบบไม่ได้เสนอคำไว้ด้วย แล้วสกัดเองได้ |
| ค้นหา + กรองตามหมวด | ค้นได้ทั้งคำและวลี · กรองดูเฉพาะหมวดที่สนใจ |
| จำที่เลือกไว้ | เก็บในเครื่องอัตโนมัติ ปิดหน้าแล้วเปิดใหม่ยังอยู่ |
| ส่งออก | ได้ผลเป็นตาราง **คำ + วลีตั้งต้น + เลขบรรทัด + ที่มา (ระบบเสนอ/สกัดเอง)** · คัดลอกหรือบันทึกเป็นไฟล์ก็ได้ |

## ง · ภาพรวม: คำใหม่ชี้ไปหมวด/กิ่งไหนบ้าง

### ๑. หมวดที่คำใหม่ไปลงเยอะที่สุด

| อันดับ | หมวด | คำใหม่ | อ่านได้ว่า |
|---|---|---|---|
| ๑ | หมวด ๓ กริยา ท่าทาง | ๑๓๙ | เกินคาด — มากกว่าหมวดอื่นเกือบเท่าตัว · ยืนยันว่าคลังชุดนี้เป็นคลัง "การกระทำ" มากกว่าคลัง "คำสวย" |
| ๒ | หมวด ๖ คำปรุงแต่ง | ๘๓ | คำเปรียบ (ดุจ/ราวกับ/ประหนึ่ง) เยอะมาก · กิ่ง "คำเปรียบ/อุปมา" ที่ตั้งเผื่อไว้ตอนเกลาหมวด ๖ มีคำมาลงจริงแล้ว |
| ๓ | หมวด ๒ รูปลักษณ์ | ๗๐ | ส่วนใหญ่เป็นอวัยวะ/ส่วนของร่างกายที่โครงเดิมยังไม่มีกิ่งรองรับ |
| ๔ | หมวด ๑ บรรยากาศ | ๕๘ | หนักไปทางแสง-มืด-ฝน-ทะเล |
| ๕ | หมวด ๕ สภาวะภายใน | ๕๗ | กลัว/โกรธ/เศร้า เป็นหลัก ตรงกับแนวนิยายสืบสวน |
| ๖ | หมวด ๔ เสียง | ๔๑ | เยอะกว่าที่คิด — เสียงจากปากคน + เสียงเลียนแบบ |

### ๒. กิ่งที่คำใหม่ชี้ว่ายังขาด (เพิ่มจาก ๔๘ กิ่งที่เสนอไว้รอบก่อน)

| หมวด | กิ่งที่คำใหม่ชี้ว่าน่าจะต้องมี | คำที่เป็นหลักฐาน |
|---|---|---|
| ๒ รูปลักษณ์ | **กิ่งอวัยวะรายส่วนที่ยังไม่มี** — สันหลัง · หว่างนิ้ว · สีข้าง · โหนกแก้ม · หางตา · ก้นบึ้งของช่องท้อง | โครงเดิมมีกิ่งดวงตา/ผม/ผิว แต่ไม่มีที่เก็บ "ส่วนของร่างกายอื่น ๆ" |
| ๒ รูปลักษณ์ | **ขนและเครื่องเครา** — ขนอ่อน · เครื่องเครา · โกนเกลี้ยงเกลา · สั้นเกรียน · หงอกแซม | กิ่งผมมีแล้ว แต่ขน/หนวดเครา/การโกน ยังไม่มีบ้าน |
| ๔ เสียง | **เสียงเลียนเสียงล้วน** — แกรกๆ · ต๊อกแต๊ก · พั่บๆ · โครม · จ้อกแจ้ก · เอื๊อก | โครงเดิมจัดเสียงตาม "แหล่งกำเนิด" ยังไม่มีกิ่งเก็บคำเลียนเสียงตรง ๆ |
| ๔ เสียง | **คุณภาพน้ำเสียง** — หางเสียง · เสียงหลง · แหลมสูง · ขาดห้วง · สั่นรัว · ขุ่นหมอง | ต่างจาก "เสียงจากปาก" ตรงที่บรรยาย *เนื้อเสียง* ไม่ใช่ *การกระทำ* |
| ๓ กริยา | **การมองแบบต่าง ๆ** — กวาดตา · สอดส่ายสายตา · เบิกตา · กรอกตา · ประสานสายตา · หลบตา | มีคำกลุ่มนี้เยอะมากจนน่าจะซอยเป็นกิ่งย่อยของตัวเอง |
| ๓ กริยา | **การลงมือทำร้าย/ฆ่า** — ปลิดชีวิต · คร่าชีวิต · บดขยี้ · จิกหัวลากตัว · แหลกละเอียด | ตรงกับที่รอบก่อนเสนอไว้แล้ว · รอบนี้มีคำมาเติมอีก |
| ๕ สภาวะภายใน | **ความรู้สึกทางกายที่คนนอกมองไม่เห็น** — เย็นสันหลังวาบ · ราวกลืนก้อนตะกั่วลงไป · ราวถูกถ่วงด้วยตะกั่ว · หนักอึ้ง | กิ่ง "กายใน" มีแล้ว แต่คำกลุ่มนี้เป็น *คำเปรียบของความรู้สึกทางกาย* อาจต้องซอยแขนงเพิ่ม |
| ๖ คำปรุงแต่ง | **คำเปรียบ ดุจ/ราวกับ/ประหนึ่ง** — ดุจแร้ง · ดุจซากฟอสซิล · ดุจขนห่าน · ดุจเปลเด็ก · ราวกับผ้าขี้ริ้ว · ราวลูกเห็บตก | กิ่งนี้ตั้งเผื่อไว้แล้ว · รอบนี้มีคำมาลงจริง ๑๐ กว่าคำ |
| ๑๒ ความเชื่อ | เติมคำให้หมวดใหม่ — ชะตากรรม · ถึงฆาต · พรหมลิขิต · มนตร์สะกด · งมงาย · จาริกแสวงบุญ | ยืนยันอีกชั้นว่าหมวด ๑๒ ที่ตั้งไว้จำเป็นจริง |
| ๑๓ ภาษา | เติมคำให้หมวดใหม่ — พรรณนา · ประพันธ์ · สาธยาย · เท้าความ · ชักแม่น้ำทั้งห้า · ทะลุกลางปล้อง | เช่นเดียวกัน — หมวด ๑๓ มีคำมาลงจริงแล้ว ๑๒ คำ |

### ๓. ข้อสังเกตที่น่าสนใจ

- **หมวด ๗ (คำทับศัพท์) ได้แค่ ๑ คำ** (`โอ๊ก` จาก "โอ๊กขึ้นดกครึ้ม" = ต้นโอ๊ก) — คลังชุดใหม่นี้เป็นนิยายสืบสวนแนวคลาสสิก แทบไม่มีคำทับศัพท์เลย
- **หมวด ๙ (อื่น ๆ) ได้แค่ ๘ คำ** — แปลว่าโครง ๑๓ หมวดที่เหลือครอบคลุมได้เกือบหมดแล้ว ซึ่งเป็นสัญญาณดี
- **คำที่ก้ำกึ่งที่สุด** คือกลุ่มคำสั้น ๆ ในหมวด ๖ (พลัน · ระคน · ลิบๆ · มหันต์) — เก็บไว้ตามกฎ "ก้ำกึ่งสกัดไว้ก่อน" ตัดทิ้งได้เลยถ้าไม่ชอบ

### ๔. 🪞 คำเปรียบในลิสต์นี้ ต้องติดกิ่ง "ของจริงที่มันสื่อถึง" ด้วย

**กฎที่เจ้าของตั้งไว้** — คำเปรียบไม่ได้อยู่แค่กิ่ง "คำเปรียบ/อุปมา" ของหมวด ๖ แต่ต้อง **ติดกิ่งของสิ่งที่มันสื่อถึงด้วย (หลายกิ่ง)**
ตัวอย่าง: `นกเหล็กหลายตันกำลังเหินเวหา` = เครื่องบิน → ต้องติด **หมวด ๑๐ กิ่งยานพาหนะทางอากาศ** ด้วย
**เหตุผล:** คนที่ค้นคำว่า "เครื่องบิน" ต้องเจอวลีนี้ · ถ้าเก็บไว้แต่กิ่งคำเปรียบ = ค้นด้วยความหมายไม่มีทางเจอ

คำเปรียบในลิสต์นี้ที่เข้ากฎ (ค้นชื่อคำในเครื่องมือได้เลย) :

| คำ | สื่อถึงอะไร | กิ่งที่ต้องติดเพิ่ม |
|---|---|---|
| ราวกับพิมพ์เดียวกัน | แม่พิมพ์ | หมวด ๑๐ · เครื่องมือและอุปกรณ์ |
| ราวกับถูกสาดน้ำทั่วร่าง | น้ำ | หมวด ๑ · น้ำและแหล่งน้ำ |
| ดุจซากฟอสซิล | ซากดึกดำบรรพ์ | ⚠️ **ยังไม่มีกิ่งรองรับ** |
| ราวลูกเห็บตก | ลูกเห็บ | หมวด ๑ · ท้องฟ้าและภูมิอากาศ |
| ราวกับผ้าขี้ริ้ว | ผ้า | หมวด ๑๐ · เนื้อผ้าและวัสดุ (คู่กับคำ `ผ้าขี้ริ้ว` ที่อยู่หมวด ๑๐ แล้ว) |
| ดุจแร้ง | แร้ง (สัตว์) | หมวด ๑ · สัตว์ |
| ราวกับเงา | เงา | หมวด ๑ · เงา |
| ดุจขนห่าน | ห่าน (สัตว์) | หมวด ๑ · สัตว์ |
| ดุจภูเขาลูกย่อม | ภูเขา | หมวด ๑ · ภูมิประเทศ |
| ดุจสตรีถูกดึงผ้าคลุมหน้าออก | ผ้าคลุมหน้า | หมวด ๑๐ · เครื่องสวมศีรษะและผ้าคลุม |
| ดุจเปลเด็ก | เปลเด็ก | หมวด ๑๐ · เครื่องเรือนสำหรับนั่งและนอน |
| ราวกลืนก้อนตะกั่วลงไป · ราวถูกถ่วงด้วยตะกั่ว | ตะกั่ว (โลหะ) | ⚠️ **ยังไม่มีกิ่งรองรับ** |
| เนินเขาลูกย่อม | เนินเขา | อยู่หมวด ๑ ภูมิประเทศ แล้ว — ต้องติด **หมวด ๒ · หัวเข่า** เพิ่ม (ของจริงที่ถูกเปรียบคือหัวเข่าคน) |

**🌿 กิ่งที่กฎนี้ทำให้เห็นว่ายังขาด**

| หมวด | กิ่งที่ยังไม่มี | คำที่เป็นหลักฐาน |
|---|---|---|
| ๑๐ สิ่งของ | **วัสดุและโลหะดิบ** (ตะกั่ว · เหล็ก · ทองแดง) — ตอนนี้มีแต่ "เนื้อผ้าและวัสดุ" ซึ่งอยู่ใต้กิ่งเครื่องแต่งกาย ใช้กับโลหะไม่ได้ | ราวกลืนก้อนตะกั่วลงไป · ราวถูกถ่วงด้วยตะกั่ว · **นกเหล็ก**หลายตัน |
| ๑ ธรรมชาติ | **ซากดึกดำบรรพ์และหิน** หรืออย่างน้อยกิ่ง "หินและแร่" | ดุจซากฟอสซิล |

🔑 **ข้อค้นพบที่สำคัญกว่าตัวกิ่ง** — กฎนี้ทำให้เห็นว่า **คลังต้องมีกิ่งของ "ของพื้นฐาน" ไว้เสมอ แม้จะไม่เก็บคำพื้นฐาน**
คลังไม่มีคำว่า "เครื่องบิน" (ธรรมดาเกินไป ไม่ใช่คำที่สนใจ) แต่ต้องมีกิ่งยานพาหนะทางอากาศ **เพราะคำเปรียบจะมาลงตรงนั้น**
→ นี่เป็นเหตุผลที่หนักที่สุดของกฎเดิม _"กิ่ง ๐ คำ ไม่ใช่เหตุผลห้ามซอย"_
