# สเปกงาน · หน้าต่างคำ (Word Window)

> เอกสารนี้ทำไว้ให้ **ส่งต่อให้คนอื่นหรือ AI ตัวอื่นทำงานต่อได้ทันที** โดยไม่ต้องมีบริบทอะไรมาก่อน
> อ่านคู่กับม็อคอัพ `docs/word-web-mockup.html` (เปิดไฟล์ตรงได้เลย ไม่ต้องต่อเน็ต)
> เขียน 26 ก.ค. 2569

---

## ๑ · สรุปสั้นที่สุด

ต้องการ **หน้าต่างที่เด้งขึ้นมาตอนกดคำในหน้าคลังคำ** ซึ่งทำสองอย่างพร้อมกัน

1. **แสดงเส้นที่โยงคำนั้นกับทุกอย่างในคลัง** — แตกมาจากวลีไหน แตกต่อไปเป็นคำอะไร อยู่หมวดไหน กิ่งไหน มาจากนิยายเรื่องไหน
2. **แก้ไขได้ในหน้าต่างเดียวกัน** — แก้คำ ความหมาย ชนิด หมวด กิ่ง เรื่อง ลบคำ ทั้งหมดจบในนี้

ตอนนี้เว็บมีหน้าต่างแก้ไขอยู่แล้ว แต่ **ไม่มีส่วนเส้นโยงเลย** และฐานข้อมูลก็ยังเก็บเส้นโยงไม่ได้ → งานนี้จึงมีทั้งฝั่งหน้าจอและฝั่งฐานข้อมูล

## ๒ · เว็บนี้คืออะไร

**คลังคำ (Word Bank)** — เว็บส่วนตัวของนักเขียนนิยายหนึ่งคน ใช้เก็บคำงาม วลี และประโยคสวย ๆ ที่เจอตอนอ่านนิยาย
ผู้ใช้วางข้อความที่เก็บมาลงไป แล้วให้ AI ช่วยแก้คำสะกด สกัดคำเด่นออกจากประโยคยาว และจัดเข้าหมวดหมู่ให้อัตโนมัติ

**มี ๕ หน้าหลัก**

| หน้า | ทำอะไร |
|---|---|
| เพิ่มคำ | วางข้อความ เลือกผู้ช่วย AI แล้วกดให้จัดคำ |
| ตรวจทาน | ดูผลที่ AI จัดมา แก้ไข ย้ายหมวด แล้วค่อยกดบันทึกเข้าคลัง · แบ่งเป็น "ช่อ" (หนึ่งช่อ = หนึ่งครั้งที่กดจัดคำ) |
| **คลังคำ** | **ต้นไม้หมวดหมู่ยุบขยายได้ + การ์ดคำ — งานนี้อยู่ที่หน้านี้** |
| ประวัติ & สถิติ | ประวัติการเรียก AI ค่าใช้จ่าย จำนวนคำ |
| เกี่ยวกับ | ข้อมูลแอป |

**ธีม** กระดาษวรรณกรรม — พื้นครีม หมึกน้ำตาล ฟอนต์ไทยมีเชิง (ไตรรงค์) และฟอนต์ลายมือ (ชาญมั่น) เฉพาะหัวเรื่อง

## ๔ · ของเดิมที่มีอยู่แล้ว (ห้ามทำพัง)

### หน้าต่างแก้ไขคำเดิม — `renderEditModal` ใน `components/pages/modals.jsx`

กดการ์ดคำในหน้าคลังคำ → `app.openEdit(w)` → ตั้ง state `modal:'edit', editing:{...w}` → เด้งหน้าต่างที่มี

| ช่อง | ชนิด | หมายเหตุ |
|---|---|---|
| คำ / วลี | ช่องพิมพ์ | |
| ความหมาย | ช่องพิมพ์ | ไม่บังคับ |
| หมวด | ดรอปดาวน์ | เลือกได้หมวดเดียว |
| จากเรื่อง | ช่องพิมพ์ + รายการแนะนำ | เลือกได้เรื่องเดียว |
| หมวดย่อย | ชิปหลายอัน มีปุ่ม ✕ ลบ + ช่องเส้นประ "＋ เพิ่มกิ่ง แล้วกด Enter" | กิ่งที่ยังไม่มีในคลังติดป้าย ✦ สีเขียว |
| ปุ่ม | ลบคำนี้ (ซ้าย) · ยกเลิก · บันทึก (ขวา) | |

- บันทึก → `app.saveEdit` → `PATCH /api/words/{id}` แล้วอัปเดต state ทันที
- ลบ → `app.deleteFromEdit` → `DELETE /api/words/{id}`
- กรอบ: พื้น `#f7f0e0` ขอบ `#e0d0ac` มุมโค้ง 16 · ฉากหลัง `rgba(58,47,40,.4)` + เบลอ 3px
- ความกว้างปัจจุบัน `min(460px, 100%)` = **แนวตั้ง** — งานนี้จะเปลี่ยนเป็นแนวนอน

### ตัวไฮไลต์หลายสี — มีอยู่แล้วในหน้าตรวจทาน

`components/pages/review.jsx` มีฟังก์ชัน `highlightColored(sentence, words, offset)` ที่ระบายสีคำที่ AI ดึงออกมาจากประโยค คนละสีต่อคำ
ใช้จานสี `PAL` จาก `components/helpers.js`

```js
export const PAL = ['#8f6b4a', '#5f7f92', '#a86a79', '#6f8a56', '#7c6a99', '#3f7d6c'];
```

🔑 **งานนี้ต้องใช้จานสีชุดเดียวกันนี้** เพื่อให้คำสกัดหน้าตรวจทานกับหน้าคลังคำสีตรงกัน

## ๕ · ฐานข้อมูลตอนนี้ และช่องว่าง ๓ จุด

### ตาราง `wb_words` (คลังคำจริง)

```
id uuid · text · original_text · meaning · reason
category_id text        ← หมวดเดียวต่อคำ
subcategory text
subpath text            ← กิ่งหลัก = subpaths[0] เขียนคู่กันเสมอ
subpaths jsonb          ← ติดได้หลายกิ่ง แต่ทุกกิ่งต้องอยู่หมวดเดียวกัน
kind text               ← 'word' | 'phrase' | 'sentence'
highlight text
novel text              ← เรื่องเดียวต่อคำ
reviewed bool · created_at
```

### ช่องว่างที่ทำให้ทำงานนี้ไม่ได้ถ้าไม่แก้ฐานข้อมูล

| ต้องการ | ของจริงตอนนี้ |
|---|---|
| คำหนึ่งโยงไปหา **วลีแม่ได้หลายวลี** | `wb_words` **ไม่มีคอลัมน์เก็บวลีแม่เลยสักช่อง** · มีแค่ห้องพักตรวจทาน `wb_review.source` และเก็บได้วลีเดียว |
| คำหนึ่งอยู่ได้ **หลายหมวด** | `category_id` เป็นคอลัมน์เดี่ยว |
| คำหนึ่งมาจาก **หลายเรื่อง** | `novel` เป็นคอลัมน์เดี่ยว |

### 🔴 บั๊กที่ต้องแก้ไปพร้อมกัน

`app/api/words/route.js` ตอนกด "บันทึกเข้าคลัง" จากหน้าตรวจทาน **ไม่ได้เขียนช่อง `source` ลงไปเลย** เพราะปลายทางไม่มีคอลัมน์ให้ลง
→ **ทุกวันนี้ข้อมูล "คำนี้ตัดมาจากประโยคไหน" หายทันทีที่กดบันทึก**

### ตัวเลขจากคลังจริง ที่บอกว่าทำไมต้องแก้

| เรื่อง | จำนวน |
|---|---|
| คำในคลังเดิมที่ **ถูกแตกเป็นหลายแถวเพราะคำหนึ่งอยู่ได้หมวดเดียว** | **29 คำ → 58 แถว** |
| คำที่มีอยู่ทั้งคลังเดิมและคลังชุดใหม่ (จะชนกันตอนรวม) | **67 คำ** |
| คำในคลังชุดใหม่ที่เกาะกิ่งข้ามหมวด | **662 คำ** |
| คำที่แตกมาจากวลีแม่มากกว่าหนึ่งวลี | **17 คำ** |

ตัวอย่างที่เห็นภาพชัดที่สุด — **`ล้มระเนระนาด`** คลังเดิมเก็บเป็น **๒ แถวแยกกัน** (หมวด 1 ความเก่า/ความเสียหาย และ หมวด 3 การเสียหลัก) ทั้งที่เป็นคำเดียวกัน เพราะระบบไม่ยอมให้คำเดียวอยู่สองหมวด

## ๖ · สิ่งที่ต้องการ (สเปกหน้าต่างคำ)

### ๖.๑ รูปทรง

- เป็น **ป๊อปอัปเด้งทับหน้าคลังคำ** เหมือนหน้าต่างแก้ไขเดิม (ฉากหลังทึบ + เบลอ)
- **วางแนวนอน** แบ่งสองฝั่ง — ซ้ายกว้างกว่า
- จอแคบ (≤900px) ตกลงมาเป็นคอลัมน์เดียว ซ้อนบนล่าง

```
┌──────────────────────────────┬───────────────────┐
│  ผังเส้นโยง                  │  แก้ไข            │
│  (ประมาณ 70%)                │  (ประมาณ 30%)     │
└──────────────────────────────┴───────────────────┘
```

### ๖.๒ ฝั่งซ้าย — ผังเส้นโยง (ของใหม่ทั้งหมด)

เรียงจากบนลงล่าง

**ก) วลีแม่** (ถ้ามี) — วางไว้เหนือคำหลัก
- แสดงวลีเต็ม โดย **ไฮไลต์ตัวคำที่กำลังดูอยู่ในวลีนั้น**
- **มีเส้นโค้งลากลงมาหาคำหลัก**
- กดแล้วกระโดดไปเปิดหน้าต่างของวลีนั้นแทน
- ถ้าไม่มีวลีแม่ → ไม่ต้องแสดงส่วนนี้ (คำนั้นเก็บมาเอง)

**ข) คำหลัก** — ต้องเด่นที่สุดในหน้าต่าง
- การ์ดกรอบหนา ๒ พิกเซล สีน้ำตาลเข้ม + เงา วางกึ่งกลาง
- ตัวอักษรใหญ่ หนา
- มีป้ายเล็กสีแดงชาดกำกับว่า "วลีตั้งต้น" หรือ "คำที่กำลังดู"
- ใต้คำมีบรรทัดสรุป: ชนิด · เกาะอยู่กี่กิ่ง กี่หมวด · เจอกี่เรื่อง · ความหมาย
- 🔴 **ถ้าคำนี้มีคำสกัดออกมา ต้องระบายสีคำเหล่านั้นในตัววลี คนละสี** ตามจานสี `PAL`

**ค) คำที่แตกออกมา** (ถ้ามี) — ชิปสีเดียวกับที่ระบายไว้ในวลี
- 🔴 **แต่ละชิปต้องมีเส้นโค้งลากจากคำที่ระบายสีในวลี ลงมาหาชิปนั้น สีเดียวกัน**
- คำที่ซ้อนอยู่ในคำที่ยาวกว่า (เช่น `มืดครึ้ม` อยู่ใน `ท้องฟ้ามืดครึ้ม`) ระบายสีทับกันไม่ได้ → **ลากเส้นประออกจากคำยาวที่ครอบมันแทน** · **ห้ามมีชิปไหนไม่มีเส้น**
- กดชิปแล้วกระโดดไปเปิดหน้าต่างของคำนั้น

**ง) หมวดและกิ่ง** — แบบผังใยความคิด (mind map)
- **หนึ่งแถวต่อหนึ่งหมวด** · ป้ายหมวดเป็นก้อนสีประจำหมวด (เลขหมวด + ชื่อไทย)
- **มีเส้นจากคำหลัก แยกลงมาหาป้ายหมวดแต่ละอัน**
- **จากป้ายหมวด แยกต่อไปหากิ่งย่อยของหมวดนั้นอีกชั้น** (เส้นสีเดียวกับหมวด)
- กิ่งแต่ละอันมีปุ่ม ✕ ลบ · ท้ายแต่ละหมวดมีปุ่ม "＋ เพิ่มกิ่งในหมวดนี้" · ท้ายสุดมีปุ่ม "＋ เพิ่มหมวด"
- กิ่งที่ยังไม่มีในคลังติดป้าย ✦ (ของเดิมมีอยู่แล้ว) · กิ่งที่มาจากคลังเดิมทำเส้นประให้เห็นว่าคนละคลัง

### ๖.๓ ฝั่งขวา — ช่องแก้ไข (ยกของเดิมมา)

ใช้ช่องเดียวกับ `renderEditModal` ทุกช่อง — คำ/วลี · ความหมาย · ชนิด · หมวดหลัก · จากเรื่อง · ปุ่ม ลบคำนี้ / ยกเลิก / บันทึก
**ยกเว้นชิปหมวดย่อย** ที่ย้ายไปอยู่ในผังฝั่งซ้ายแล้ว

### ๖.๔ พฤติกรรม

- กดวลีแม่หรือคำลูก = **เปลี่ยนคำที่กำลังดูในหน้าต่างเดิม** ไม่ใช่เปิดหน้าต่างใหม่ซ้อน
- ควรมีปุ่มย้อนกลับ เพราะเดินไปได้หลายชั้น
- เส้นทั้งหมดต้องคำนวณใหม่เมื่อจอเปลี่ยนขนาด

### ๖.๕ วิธีวาดเส้น (สำคัญ ทำผิดจะเพี้ยน)

**ห้ามคำนวณตำแหน่งล่วงหน้า** เพราะข้อความไทยขึ้นบรรทัดไม่แน่นอน ความยาวคำต่างกันทุกคำ
วิธีที่ใช้ในม็อคอัพและพิสูจน์แล้วว่าได้ผล

1. เรนเดอร์ทุกอย่างเป็นการไหลปกติก่อน (ไม่ต้องกำหนดตำแหน่ง)
2. วัดตำแหน่งจริงของทุกชิ้นด้วย `getBoundingClientRect()` เทียบกับกรอบผัง
3. วาดเส้นโค้งทับด้วย SVG ที่วางไว้ **ข้างหลัง** เนื้อหา (`position:absolute; inset:0; z-index:0`)
4. คำที่ไฮไลต์อาจขึ้นบรรทัดใหม่ ต้องใช้ `getClientRects()[0]` ไม่ใช่ bounding box ทั้งก้อน

## ๗ · ข้อเสนอฝั่งฐานข้อมูล (ยังไม่เคาะ)

เพิ่ม **ตารางเส้นเชื่อม ๓ ชุด** แทนที่จะเก็บความสัมพันธ์เป็นข้อความในตัวคำ

| ตาราง | เก็บอะไร | ตอบข้อไหน |
|---|---|---|
| `wb_word_links` | คู่ (คำลูก ↔ วลีแม่) **ผูกด้วยรหัสแถว ไม่ใช่ข้อความ** + บอกว่าใครแตก (ai/owner) | วลีแม่หลายวลี · ไม่มีเส้นเลย = เก็บมาเอง |
| `wb_word_branches` | หนึ่งแถว = คำ ๑ คำ ติดกิ่ง ๑ กิ่ง · **`category_id` อยู่ที่เส้น ไม่ใช่ที่คำ** | กิ่งข้ามหมวด |
| `wb_word_novels` | หนึ่งแถว = คำ ๑ คำ เจอในเรื่อง ๑ เรื่อง | หลายเรื่อง |

🛡 **ข้อบังคับ: คอลัมน์เดิมต้องคงไว้ทั้งหมดและเขียนคู่กันเสมอ**
(`category_id` · `subpath` · `subpaths` · `novel`) เหมือนที่ระบบทำกับ `subpath`/`subpaths` อยู่แล้ว
→ ทุกหน้าที่มีอยู่ทำงานเหมือนเดิมเป๊ะ ไม่ต้องรื้อทั้งเว็บพร้อมกัน

**เหตุผลที่ต้องผูกด้วยรหัสแถว ไม่ใช่ข้อความ** — ถ้าเก็บเป็นข้อความ พอแก้คำแม่ทีเดียวเส้นขาดทันทีโดยไม่มีใครรู้ และถามย้อนกลับ ("วลีนี้แตกออกเป็นคำอะไรบ้าง") ไม่ได้ ต้องไล่อ่านทุกแถว

**ไฟล์ SQL** ต้องตั้งชื่อต่อจากของเดิม → `scripts/014_word_web.sql` และ **ต้องเปิด RLS แบบปิดตายเหมือนตารางอื่น**

## ๑๐ · สิ่งที่ยังไม่เคาะ (ต้องถามเจ้าของก่อนตัดสินใจ)
