# คำที่สงสัยว่าสะกดผิด

> **5 คำ** · ผู้ช่วยไม่ได้แก้ให้ คงข้อความไว้ตามเดิม แล้วเสนอคำที่คิดว่าใช่มาให้พี่กันเคาะ

> เคสที่ทำให้ตั้งกฎนี้: `พลวัน` ถูกเก็บ จัดหมวด ติดกิ่งไปครบ กว่าจะรู้ว่าคำที่ถูกคือ `พัลวัน`

| ข้อความในคลัง | ที่ผู้ช่วยสงสัย | อยู่เล่มไหน |
|---|---|---|
| **กระหืดหอบ** | ⚠ ไม่แน่ใจว่ามีคำว่า กระหืดหอบ ในภาษาไทย · น่าจะเป็น กระหืดกระหอบ | คินดะอิจิยอดนักสืบ ตอน บทเพลงปีศาจ |
| **ฉาบฉาย** | ⚠ ไม่แน่ใจว่ามีคำว่า ฉาบฉาย ในภาษาไทย · น่าจะเป็น ฉาบฉวย | เสียงกระซิบจากความมืด |
| **ชุบมือเปิด** | ⚠ ไม่แน่ใจว่ามีคำว่า ชุบมือเปิด ในภาษาไทย · น่าจะเป็น ชุบมือเปิบ | คินดะอิจิยอดนักสืบ ตอน บทเพลงปีศาจ |
| **ท่านโยกโย้งอแงมาก** | ⚠ ไม่แน่ใจว่ามีคำว่า โยกโย้ง ในภาษาไทย · น่าจะเป็น โยกโย้ (บิดพลิ้ว ไม่ตรงไปตรงมา) | คินดะอิจิยอดนักสืบ ตอน บทเพลงปีศาจ |
| **เต็มเหนียว** | ⚠ ไม่แน่ใจว่ามีคำว่า เต็มเหนียว ในภาษาไทย · น่าจะเป็น เต็มเหนี่ยว | คินดะอิจิยอดนักสืบ ตอน บทเพลงปีศาจ |
