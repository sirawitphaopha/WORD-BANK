## กิ่งที่ถอนจริง 4 เส้น (ปลอดภัย)

> ถอนเฉพาะกรณี **ถอนกิ่งแม่ทั้งที่ยังเก็บกิ่งลูกไว้** = ละเอียดขึ้น ไม่มีข้อมูลหาย

| คำ | กิ่งแม่ที่ถอน | กิ่งลูกที่เหลือ |
|---|---|---|
| ชันเข่า | ท่าทางและภาพรวมร่างกาย / ท่านั่งและท่าเฉพาะจุด | การนั่งพักและทิ้งตัว · การห่อตัวและป้องกันตัว |
| สมส่วน | ทรวดทรงและภาพรวมของร่าง / ความงามของทั้งตัว | รูปร่างสง่างาม |
| ส่องสว่าง | แสงและเงา / แสง | แสงสว่าง |
| แมกไม้ | ธรรมชาติและสภาพอากาศ / พืชพรรณ | ป่าและหมู่ไม้หนาทึบ · ความเขียวชอุ่มและการไหวของใบไม้ |
