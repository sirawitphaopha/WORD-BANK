# รอบ M2 — ให้ผู้ช่วยตัดสินคำที่สกัด โดยไม่เห็นวลีตั้งต้น

> โฟลเดอร์นี้เก็บงานรอบเดียวทั้งหมด · สร้างอัตโนมัติ อย่าแก้มือ

## เรื่องย่อ

พี่กันจับได้จากคำว่า **`เสียว`** ว่าคำที่สกัดออกมาถูกยัดกิ่งเดียวกับวลีตั้งต้น
(`เสียว` ตัดมาจาก `เสียวสันหลังวาบด้วยความหวาดกลัว` เลยติดแต่กิ่งความกลัว ทั้งที่คำนี้ใช้ได้อีกอย่างน้อย 4 ทาง)

รอบนี้จึงลองปิดตาผู้ช่วย **ให้เห็นแค่ตัวคำล้วน ๆ** ไม่เห็นวลีตั้งต้น ไม่เห็นกิ่งเดิม ไม่เห็นหมวดเดิม
แล้วให้ตัดสินความหมายกับกิ่งใหม่ทั้งหมด

| | |
|---|---|
| คำที่ทบทวน | 394 คำ |
| คำที่ตีความได้หลายทาง | **122 คำ (31%)** |
| กิ่งที่เพิ่ม | **488 เส้น** (310 คำ) |
| คำที่ได้ความหมายใหม่ | **72 คำ** |
| กิ่งที่ถอนจริง | 4 เส้น (จากที่เสนอ 88) |

## ข้อสรุปสั้นที่สุด

🏆 **วิธีนี้ใช้ "เพิ่มกิ่ง" ได้ดีมาก แต่ใช้ "ถอนกิ่ง" ไม่ได้เลย**

ปิดวลีตั้งต้นแล้วเห็นความหมายที่บริบทเคยบัง — ได้กิ่งเพิ่ม 488 เส้น ความหมายใหม่ 72 คำ
แต่พอไม่เห็นวลีตั้งต้น ผู้ช่วยก็ไม่รู้ว่ากิ่งเดิมมีที่มาจากไหน เลยขอถอนกิ่งที่ถูกอยู่แล้วออก **88 เส้น รับได้จริงแค่ 4**

ตรงกับกฎเหล็กที่คลังมีอยู่แล้ว — *เพิ่มได้ ลดไม่ได้*

## 🔴 กันเข้าใจผิด

คำว่า **"แย้ง"** ในไฟล์ `4-drop-review.md` = **แย้งเฉพาะการถอนกิ่งเดิม ไม่ได้แย้งกิ่งใหม่**
กิ่งที่ผู้ช่วยเสนอมา **เข้าคลังไปแล้วครบทุกกิ่ง ไม่มีกิ่งไหนถูกปัดทิ้ง**

**ผลสุทธิของทุกคำ = ได้กิ่งเพิ่ม ไม่เสียกิ่งเดิม** (ยกเว้น 4 เส้นที่ตั้งใจถอน)
