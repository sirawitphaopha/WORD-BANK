# ๔ · 88 เส้นที่ผู้ช่วยขอถอนกิ่ง

> [กลับสารบัญ](./README.md)

## 🛑 อ่านตรงนี้ก่อน — ไม่งั้นตีความกลับด้านได้

### ๑. 88 เส้นนี้คือ "ข้อเสนอ" ไม่ใช่สิ่งที่ถอนไปแล้ว

ผู้ช่วยที่ไม่เห็นวลีตั้งต้นเสนอให้ถอนกิ่งเดิมออก 88 เส้น · แคลร์อ่านเองทุกเส้นแล้ว **รับ 4 ปฏิเสธ 84**

กิ่งในคลังจริง **ไม่ได้ถูกถอนออกเลย ยกเว้น 4 เส้นที่รับ** (อยู่กลุ่ม ฉ ท้ายไฟล์)

### ๒. คำว่า "แย้ง" = แย้งเฉพาะการถอนกิ่งเดิม **ไม่ได้แย้งกิ่งใหม่**

🔴 **จุดนี้สำคัญที่สุด** — กิ่งที่ผู้ช่วยเสนอมา **เข้าคลังไปแล้วครบทุกกิ่ง ไม่มีกิ่งไหนถูกปัดทิ้ง**
การที่แคลร์ไม่ให้ถอนกิ่งเดิม **ไม่ได้แปลว่าไม่เอากิ่งใหม่** — เอาทั้งคู่

**ผลสุทธิของทุกคำในไฟล์นี้ = ได้กิ่งเพิ่ม ไม่เสียกิ่งเดิม**

### ๓. ตัวอย่างที่พี่กันหยิบมาถามเอง — `กระเพื่อมขึ้นลง`

วลีตั้งต้น `กระเพื่อมขึ้นลงตามระลอกคลื่น`

| | |
|---|---|
| ผู้ช่วยขอถอน | ม.1 น้ำและแหล่งน้ำ |
| ผู้ช่วยขอเพิ่ม | ม.3 ระบบหายใจ |
| แคลร์แย้ง | ไม่ให้ถอนกิ่งน้ำ (เพราะวลีมีคำว่า "ระลอกคลื่น") |

**สุดท้ายคำนี้อยู่ 3 กิ่ง ไม่ได้ย้ายไปไหน ไม่ได้เสียกิ่งไหน**

- ✅ **ม.1 › ธรรมชาติและสภาพอากาศ / ความเคลื่อนไหวในฉาก** — กิ่งเดิม
- ✅ **ม.1 › ธรรมชาติและสภาพอากาศ / น้ำและแหล่งน้ำ** — กิ่งเดิม · กิ่งที่ผู้ช่วยขอถอน แต่คงไว้
- ➕ **ม.3 › ปฏิกิริยาตอบสนองทางกาย / ระบบหายใจ** — เพิ่มรอบนี้

จาก 2 กิ่ง → **3 กิ่ง** · กิ่งน้ำที่แคลร์แย้งไว้ยังอยู่ · กิ่งหายใจที่ผู้ช่วยเสนอก็ได้เข้าไปด้วย

> คอลัมน์สุดท้ายของทุกตารางข้างล่างนี้ **อ่านจากคลังจริง** ไม่ใช่คำนวณเอง
> เปิดดูได้เลยว่าแต่ละคำสุดท้ายอยู่กิ่งอะไรบ้าง

## ประเด็นที่วิจัยต่อได้

1. **กลุ่ม ช (ถกเถียงได้จริง)** — `พลวัน` กับ `เล่าลือ` รอพี่กันเคาะว่าตอนเก็บคำตั้งใจให้แปลว่าอะไร
2. **ถ้าให้ผู้ช่วยเห็นวลีตั้งต้นเฉพาะตอนตัดสินว่าจะถอน จะแก้ได้ไหม** — ขั้นหาความหมายยังปิดตาเหมือนเดิม แต่ขั้นถอนเปิดให้เห็น น่าจะได้ทั้งความหมายใหม่และไม่ถอนผิด
3. **กลุ่ม ง ชี้ว่าปัญหาอยู่ที่ขั้นเลือกกิ่ง ไม่ใช่ขั้นเข้าใจคำ** — ถ้าบังคับให้ผู้ช่วยไล่เลือกกิ่ง**ทีละความหมาย** แทนที่จะเลือกทีเดียวจบ อาจได้กิ่งครบขึ้นโดยไม่ต้องยิงหลายรอบ
4. **กิ่งที่เสนอมาแทน ยังไม่ได้เอาเข้าคลัง** — ในนั้นมีกิ่งที่ดีปนอยู่ (เช่น `คมกริบ` เสนอกิ่งอาวุธมีคม · `เสียว` เสนอกิ่งราคะและเสน่หา) รอบหน้าเก็บส่วนนี้เพิ่มได้
5. **เกณฑ์ "กิ่งแม่ vs กิ่งลูก"** — 4 เส้นที่รับ ล้วนเป็นการถอนกิ่งแม่แล้วเก็บกิ่งลูก ถ้าตั้งเป็นกฎอัตโนมัติได้ ก็ไม่ต้องมาไล่ตรวจด้วยตาทุกเส้น
