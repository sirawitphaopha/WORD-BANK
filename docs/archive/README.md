# 🗄 `docs/archive/` — งานเก่า เก็บไว้เป็นประวัติ

เจ้าของคลังสั่งตั้ง 3 ส.ค. 2569 — _"ที่เหลืองานเก่าต่าง ๆ ก็สร้างโฟลเดอร์ด้วย แล้วตั้งว่าอะไรก็ได้ที่บอกว่ามันเก่า"_

เดิม `docs/` มีไฟล์กองรวมกันร้อยกว่าไฟล์ จนหาของที่ยังใช้อยู่ไม่เจอ
ย้ายงานที่ **จบรอบไปแล้ว** มาไว้ที่นี่ เหลือเฉพาะของที่ยังทำงานอยู่ไว้ที่ `docs/`

🔒 **เก็บไว้ ไม่ลบ** — หลายไฟล์เป็นหลักฐานของงานที่เจ้าของคลังลงแรงเอง
และเป็นตัวเทียบว่าคำไม่หายระหว่างทาง
