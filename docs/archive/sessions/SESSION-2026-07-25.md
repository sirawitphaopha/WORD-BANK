## 🗂 flow เกลาหมวด (กันลืม · เต็มใน `docs/grooming-filemap.md`)
- **ต้นฉบับความจริง = `docs/catN-redesign.md`** (ไฟล์อื่นสร้างตาม)
- **แก้กิ่ง 1 จุด (ชื่อไทย/อังกฤษ/นิยาม/คำ) = ต้องไล่แก้ครบ:** ① `catN-redesign.md` → ② `catN-redesign.html` (หมวด **5·6·8·11** รัน `python3 scripts/gen_catN_html.py` · หมวด **1·2·3·4·10** แก้มือในไฟล์ .html) → ③ `python3 scripts/gen_branches.py` (อัปเดต `branches-clean.md` + `branches-data.md` + `branches-data.json`)

- **"md เฉพาะหมวด" = `branches-clean.md`** (กิ่งล้วน ไม่มีคำ ไม่มีความเห็น) — กิ่ง=หมวด · เฉพาะหมวด=เฉพาะกิ่ง

## 🔴 บทเรียนวันนี้ (แคลร์พลาดหลายครั้ง พี่กันหงุดหงิด — ห้ามซ้ำ)
1. **"md เฉพาะหมวด" = `branches-clean.md`** ไม่ใช่ "ไปเกลาหมวดใหม่" — แคลร์ตีความผิด เสียเวลา · **กิ่ง = หมวด · เฉพาะหมวด = เฉพาะกิ่ง (ไม่มีคำ)**
2. **HTML มาจาก md redesign เสมอ** — แก้ md แล้ว**ต้องซิงก์ HTML ทันที** (gen หรือแก้มือ) ไม่ใช่ "ไว้ตอน push" · แคลร์เอาแต่เลื่อน พี่กันจับได้
3. **อย่าเลื่อน commit** — ทำงานเยอะแล้วไม่ commit สักครั้ง = ถ้าเครื่องดับหายหมด · พี่กันหงุดหงิด "ทำมาไม่บันทึกอะไรเลยเหรอ" · **มี milestone = commit เก็บ**
4. **สั่งแล้วอย่าขออนุมัติซ้ำ** — พี่กัน "ต้องรอให้เราอนุมัติด้วยเหรอ เราสั่งแล้ว" · ถ้าพี่กันสั่งชัด (เช่น "แบ่งหมวดย่อย") = ทำเลย ไม่ต้องถามซ้ำ
5. **เขียนไว้ในไฟล์ชัด ๆ = อ่านให้ครบ อย่าถาม** (เคยถามหมวด 1 ว่ามีคำอะไรทั้งที่ไฟล์เขียนไว้แล้ว)
6. **บันทึกทุก flow เป็นกฎ** — พี่กันสั่ง "ทุก flow ที่ทำ ตั้งเป็นกฎกันลืม เพราะสิบกว่าหมวดมี flow ของมัน ถ้าไม่จดก็ทำมั่วทุกหมวด"
7. **แคลร์ต้องเสนอมุมตัวเอง ไม่ตามเจนทั้งหมด** — วันนี้ทำได้ดี (แย้งชื่อแคบ 3 จุดในหมวด 11) · เจนเก่งเติมกิ่งที่ขาด แต่ชอบคำ "คม/สวย" ที่บางทีแคบเกินจนเสียของ (ร่มต้องคลุมทั้งขั้ว)
