## 🔴 บทเรียนของรอบนี้ (ห้ามซ้ำ)

### 1. ทำงานเสร็จแล้วเงียบ — พี่กันต้องทวง 3 รอบติดในรอบเดียว

1. _"ไหนไฟล์สรุปทั้งหมดของชุดนี้ มีไฟล์อะไรสร้างใหม่มั่ง ทำไมไม่ส่งมาให้อ่าน"_
2. _"JSON สร้างยัง"_ ← **ยังไม่ได้สร้างจริง ๆ**
3. _"ไหนไฟล์ที่สกัด ที่เราอุตส่าห์นั่งสกัด"_

พี่กันสรุปเอง: _"แล้วถ้าเราไม่บอก จะล่มไปตลอดกาลเลยสินะ เธอควรจะต้องบอกเรา ไปบันทึกยังไงก็ได้ ให้เธอไม่ลืมเสนอ ไม่ลืมทำ"_

✅ **เช็คลิสต์ที่ต้องกวาดให้ครบก่อนบอกว่าเสร็จ (ตั้งเป็นกฎแล้ว)**
1. md สรุปผล แยกตามหมวด อ่านรู้เรื่องโดยไม่ต้องเปิดไฟล์อื่น
2. HTML คู่กับ md + ลิงก์อ่านบนมือถือ
3. JSON พร้อมขึ้นฐานข้อมูล โครงตรงกับคลังอีกก้อนเสมอ
4. ฉบับสำรองของงานที่พี่กันลงแรงเอง ต้องลงเรพ ห้ามอยู่แต่ในเครื่องมือ
5. **ส่งไฟล์ให้พี่กันจริง ๆ** ไม่ใช่แค่บอกว่ามีไฟล์

### 2. รายงานพี่กันต้องบอกแค่ "ผลลัพธ์"

พี่กัน: _"ไฟล์เว็บหรือสคริปไม่ต้องบอก เราจะรู้ไปทำไม เราต้องการ ผลลัพธ์"_
✅ บอก: ได้คำกี่คำ เข้าหมวดไหน อ่านที่ไหน · ❌ ไม่บอก: ชื่อสคริปต์ ชื่อฟังก์ชัน ชื่อไฟล์กลาง

### 3. บั๊ก 3 จุดในตัวเขียนกลับที่เจอและแก้แล้ว

| อาการ | ต้นเหตุ | แก้ยังไง |
|---|---|---|
| อ่านกิ่งพลาด 68 กิ่ง | บรรทัดกิ่งวางป้ายไว้**หลัง**ชื่อได้ (`**ชื่อกิ่ง** 🔗 — _นิยาม_) แต่ตัวอ่านต้องการ `—` ติดหลัง `**` ทันที | ยอมให้มีป้ายคั่น |
| อ่านกิ่งพลาดอีก 36 กิ่ง | บรรทัดกิ่งมี tag แนวนิยายต่อท้ายได้ (`— _นิยาม_ [อีโรติก]`) แต่ตัวอ่านจบด้วย `_` | ยอมให้มี tag ต่อท้าย |
| 🔴 **ตัวคำพัง** | ความหมายที่มี**วงเล็บซ้อน** `พรรค์นั้น (ประเภทแบบนั้น (ภาษาพูด))` → ตัวแกะใช้ `\(([^()]*)\)$` ซึ่ง match ไม่ติด **วงเล็บทั้งก้อนติดเข้าไปในตัวคำ** | ล้างวงเล็บในความหมายก่อนเขียน |
