## 👥 บริบทที่ต้องรู้ก่อน (ถ้าเพิ่งเข้ามาอ่านครั้งแรก)

- **พี่กัน** = เจ้าของโปรเจกต์ · เภสัชกรโรงพยาบาล · **ไม่มีพื้นฐานเขียน/อ่านโค้ดเลย** แต่เข้าใจตรรกะการทำงานของระบบดีมาก · ทำเว็บคนเดียว จ่ายเอง
- **แคลร์** = ผู้ช่วย AI · **ผู้หญิง** ใช้ **ค่ะ/นะคะ** (ห้าม ครับ/ผม) · แทนตัวเองว่า "แคลร์" · เรียกผู้ใช้ว่า "พี่กัน"
- **เจน** = Gemini · ที่ปรึกษาภายนอกที่พี่กันเอางานไปให้ช่วยวิเคราะห์
- 🚨 **ห้ามพูดรหัสหมวดหลังบ้าน (c0, c1, …) กับพี่กันเด็ดขาด** — เรียก "หมวด + เลข/ชื่อไทย" เท่านั้น (รหัสเริ่มนับจาก 0 เลยเลื่อนจากเลขหมวด 1 ช่อง เคยทำพี่กันสับสนหนัก)
- 🚨 **ห้าม push จนกว่าพี่กันพิมพ์คำว่า "push / พุช" ตรง ๆ** · คำว่า "ทำต่อ/ทำเลย/เอาขึ้น main" **ไม่ใช่** การอนุญาต · **หนึ่งคำสั่งพุช = พุชได้หนึ่งครั้ง** คำสั่งพุชของเมื่อวานใช้กับวันนี้ไม่ได้
- 🚨 **พี่กันใช้ speech-to-text (พูดแล้วให้เครื่องพิมพ์)** → คำที่พิมพ์ผิดจะเป็นแบบ "เสียงคล้าย" และผิดซ้ำแบบเดิมได้ · **ห้ามใช้เหตุผลว่า "ผิดซ้ำหลายบรรทัด = ตั้งใจ"**

**งานหลักที่ทำอยู่ช่วงนี้:** พี่กันส่ง **คลังคำชุดใหม่ 1,329 วลี** (เก็บจากนิยายสืบสวน **"คินดะอิจิยอดนักสืบ ตอน บทเพลงปีศาจ"**) มาให้จัดเข้าหมวด/กิ่ง

### ๒ · 🐛 บั๊ก "คำย่อยในบทบรรยายโชว์ไม่ครบ" — พี่กันจับได้เอง

**อาการ:** พี่กันอ่านบทบรรยายที่ 1 แล้วถามว่า
> _"ทำไมอันนี้ตัดคำย่อยมาน้อยจัง เราจำได้ว่าตอนเรานั่งตัด มันได้หลายคำนะ หรือเธอลบออกเพราะเห็นว่ามันซ้ำกับคำที่มีอยู่แล้ว"_

บทที่ 1 พี่กันตัดไว้ 4 คำ แต่ไฟล์รายงานโชว์คำเดียว — **พี่กันจับถูก**

**ต้นเหตุ:** 3 คำที่หาย (`ท้องฟ้าสีคราม` · `ผิวน้ำทะเลสีตะกั่ว` · `เลื่อนลอยคล้อยต่ำ`) **มีเป็นบรรทัดเดี่ยวในคลังอยู่แล้ว** (บรรทัด 1212/1213/1216)
ตอนยุบคำซ้ำตามที่พี่กันสั่ง (`build_items` ใน `scripts/gen_newwords_branches.py`) โปรแกรมข้ามการสร้างแถวคำสกัด
→ **ข้อมูลว่าคำนั้นตัดมาจากบทไหนหายไปด้วย**

🔑 **คำไม่ได้หายจากคลังเลยสักคำ** — ที่หายคือ **"เส้นเชื่อม" ระหว่างคำกับบท** ซึ่งใช้ตอนแสดงผล

**วิธีแก้:** เพิ่มช่อง **`picked_from`** (รายชื่อวลีที่พี่กันตัดคำนั้นออกมา) · ทุกครั้งที่ยุบซ้ำต้องบันทึกเส้นเชื่อมเสมอ:
```python
if t in seen:                                   # ซ้ำ → ยุบเข้าแถวเดิม
    it = items[seen[t]]
    # 🔑 เก็บ "เส้นเชื่อม" ไว้เสมอว่าพี่กันตัดคำนี้ออกมาจากวลีไหนบ้าง
    if q['source'] != it['text'] and q['source'] not in it['picked_from']:
        it['picked_from'].append(q['source'])
```
ฝั่งรายงาน (`scripts/gen_newwords_review.py`) ต้องอ่าน **2 ช่อง** ไม่ใช่ช่องเดียว:
```python
for s in ([w['source']] if w.get('source') else []) + w.get('picked_from', []):
```

**ผล:** กู้เส้นเชื่อมกลับมา **113 เส้น จาก 104 คำ** · บทบรรยายที่มีคำย่อยแสดงเพิ่มเป็น **62/80 บท** (คำย่อยรวม 154 คำ)

🚨 **บทเรียนที่ต้องจำ: การ "ยุบคำซ้ำ" ต้องเก็บความสัมพันธ์ของสิ่งที่ยุบไว้เสมอ ไม่ใช่ทิ้งทั้งแถว**
ไม่งั้นข้อมูลหายแบบเงียบ ๆ โดยที่ตัวเลขรวมยังดูถูกต้องทุกตัว (จำนวนคำไม่เปลี่ยน แต่ความสัมพันธ์หาย)

### ๓ · ฉบับ HTML กดเคาะได้ (พี่กันขอกลางทาง)

พี่กันพิมพ์แทรกมาว่า _"อ้อ ไฟล์นี้สร้าง html ให้อ่านง่ายๆหน่อย"_

- `docs/newwords-review-branches.html` (81 กิ่งใหม่)

**คุณสมบัติ:** HTML เดี่ยวเปิดตรงได้ ไม่ต้องต่อเน็ต · ธีมกระดาษ + โหมดมืด · แต่ละรายการเป็นการ์ด **กดปุ่ม เอา/ไม่เอา ได้ในตัว** + ค้นหา + กรองตามกิ่ง/หมวด/สถานะ + ปุ่มส่งออกผลการเคาะ

🛟 **ยกระบบกันงานหายจากเครื่องมือคัดคำมาทั้งชุด** (บทเรียนวันที่ 25 ก.ค. ที่พี่กันเสียงานไปเป็นพันคำ):
บันทึกทันทีทุกครั้งที่กด · **ที่เก็บ 3 ชั้น** (localStorage → sessionStorage → `window.name`) แต่ละชั้น**เขียนแล้วอ่านกลับมาเทียบจริง** ไม่ใช่แค่ดูว่าไม่ error · ป้ายสถานะให้เห็นด้วยตา + แถบเตือนแดงถ้าเก็บถาวรไม่ได้

**เทสในโครมจริงจอ 390 ทั้ง 2 ไฟล์:** กด 2 ใบ → รีเฟรช → ยังอยู่ครบ · ตัวกรองทำงาน · ไม่ล้นจอ · ไม่มี error · สลับธีมได้ทั้ง 2 ทาง (ตามเครื่อง + ปุ่มสลับของหน้าเว็บ)

⚠️ **บทเรียนธีม Artifact:** ต้องประกาศสีทั้ง 3 ที่ — `:root` · `@media (prefers-color-scheme: dark)` · **`:root[data-theme=dark]` / `[data-theme=light]`** เพราะปุ่มสลับธีมของหน้าเว็บจะแปะ `data-theme` ที่ราก และต้องชนะทั้ง 2 ทาง

🕷 **`ชักใย` ติดกิ่งการเคลื่อนไหวของสัตว์ด้วย** — พี่กันชี้ _"ชักใย นี่กริยาของสัตว์ก็ได้นะ แมงมุม"_ = ของจริงที่คำเปรียบสื่อถึง ตรงกับกฎที่พี่กันตั้งเอง · ตอนนี้ติด 3 กิ่ง

## 🕸 งานถัดไป — "ระบบโยงแบบใยแมงมุม" (พี่กันสั่งให้คุยก่อน ยังไม่ลงมือ)

พี่กันอธิบายไว้ตรงตัว:
> _"มันจะคล้ายยัยแมงมุมจังแบบ / วลีมี 111b11111c111d แตกคำย่อยเป็น b c d / แต่เราก็มีเก็บ b แยก อาจจะจากเรื่องอื่น หรือจากในเรื่องนั้น ก็ต้องโยงไปด้วย / และ b อาจจะอยู่สองหมวด 3 กิ่งย่อยก็โยงได้ / แปลว่าถ้าเรากดดูที่ b มันจะบอกเลยว่า คำนี้เป็นทั้ง 1. แตกมาจากประโยคใหญ่อาจจะ 1-2 วลีซึ่งก็โยงกลับไปได้ 2. ไม่แตกมาจากไหนเลยเพราะเก็บมาเอง 3. มาจากนิยายเรื่องนี้เรื่องนั้น 3. อยู่หมวดและกิ่งย่อยไหนบ้าง / เพราะเว็บเราต้องมีระบบนี้ น่าจะต้องสร้างใหม่ เราต้องมีระบบโยงให้แข็งแกร่ง / **คุยทำความเข้าใจก่อนนะ**"_

### 🧵 ข้อเสนอที่จะคุยกับพี่กัน (ยังไม่ทำ รอเคาะ)

**ต้นตอ:** ตอนนี้เว็บเก็บ "ความสัมพันธ์" เป็น **ข้อความก๊อปไว้ในตัวคำเอง** (เหมือนเขียน*ชื่อ*หมอบนใบยาแทน*รหัส*หมอ — เปลี่ยนชื่อแล้วชี้ผิด และถามย้อนกลับไม่ได้)
