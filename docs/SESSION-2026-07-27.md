## เรื่องที่ 1 · ปัญหาที่พี่กันจับได้จากคำว่า `เสียว`

พี่กันถามว่าคำว่า `เสียว` เก็บอยู่กิ่งไหน แล้วชี้ปัญหาเองว่า

> _"คำที่สะกัดมาจากวลีหลัก ไม่จำเป็นต้องอยู่กิ่งเดียวกับต้นฉบับนี่นา บางคำที่สะกัดอาจจะความหมายไปคนละแนวเลยก็ได้ หรือตีความได้มากมาย"_

**ตรวจด้วยเครื่องแล้วเป็นปัญหาเชิงระบบจริง** ไม่ใช่กรณีเดียว

| | คลังเดิม | คลังชุดใหม่ |
|---|---|---|
| คำสกัดที่ได้กิ่ง**เหมือนวลีตั้งต้นเป๊ะทุกกิ่ง** | 49 (12%) | 139 (25%) |
| คำสกัดที่มีความหมายกำกับ | 40% | 32% |

`เสียว` ตัดมาจาก `เสียวสันหลังวาบด้วยความหวาดกลัว` เลยได้กิ่ง "หวาดกลัวและขวัญผวา" ติดมา
ทั้งที่ตัวคำใช้ได้อีกอย่างน้อย 4 ทาง — เสียวแปลบทางกาย · หวาดเสียวระทึก · **เชิงกามารมณ์** · วาบในใจ

**ต้นตอ 2 จุด (อ่านจาก `lib/prompt.js` ฉบับจริง)**
1. คำสั่ง AI **ไม่มีกฎแยก "คำที่สกัด" ออกจาก "วลีตั้งต้น" เลย** — AI อ่านวลี ตัดคำ แล้วเขียนความหมายกับกิ่งต่อในคำตอบเดียว ภาพของวลียังค้างอยู่ในหัว
2. กฎความหมายเดิมเขียนว่า "คำธรรมดาใส่ null ได้" ซึ่งถูกสำหรับวลีตั้งต้น **แต่ผิดสำหรับคำสกัดที่หลุดบริบทมาแล้ว**

### 📖 ศัพท์ที่พี่กันเลือกเอง (ใช้ให้ตรงกันทุกที่)

พี่กันบอกเอง: _"บอกว่า วลีตั้งต้น เราเข้าใจกว่า"_

| เรียกว่า | คืออะไร |
|---|---|
| **วลีตั้งต้น** | บรรทัดที่พี่กันวางเข้าไปเอง (ช่องที่มาว่าง เพราะเป็นของต้นฉบับ) |
| **คำที่สกัด** | คำที่ระบบตัดออกมาจากวลีตั้งต้นอีกที (มีช่องบอกว่าตัดมาจากวลีไหน) |

🔴 **ห้ามเรียกว่า "คำที่พิมพ์เข้ามา"**

### ⚖️ เกณฑ์ความหมายใหม่ที่พี่กันเคาะ

พี่กันสรุปเอง: _"เก็ต คำว่าตีความได้ทางเดียว หรือหลายทางเป็นตัวตัดสิน ถ้าตีความทางเดียวก็คือเข้าใจได้ด้วยตัวเอง"_

**ตัวตัดสินไม่ใช่ "คำคุ้นหรือไม่คุ้น" แต่คือ "ตีความได้ทางเดียว หรือหลายทาง"**
- `คำราม` ตีความทางเดียว → เว้นความหมายได้
- `เสียว` คุ้นมาก แต่ตีความได้ 4 ทาง → **ต้องมีความหมายเสมอ**

## เรื่องที่ 2 · คำสั่ง AI ขึ้นฉบับที่ ๙

แก้ **ทั้งฉบับอังกฤษ (ที่ส่งจริง) และฉบับไทย (ที่โชว์บนเว็บ)** ใน `lib/prompt.js`

**เพิ่มกฎข้อ 3c / 3ค**
> คำที่ตัดออกมาจากวลีตั้งต้น ให้ประเมินจากตัวคำเอง **ห้ามลอกกิ่งของวลีตั้งต้นมาโดยอัตโนมัติ**
> ตรงกันได้ แต่ต้องตรงเพราะความหมายตรง ไม่ใช่เพราะอยู่บรรทัดเดียวกัน
> (ยกกรณีจริงของ `เสียว` ประกอบในตัวคำสั่ง)

**แก้เกณฑ์ความหมายข้อ 5d / 5ง** จาก "คำธรรมดาเว้นได้" เป็น **"ตีความได้ทางเดียว → เว้นได้ · หลายทาง → ต้องเขียนเสมอ ห้ามเว้น"**

**`lib/promptlog.js`** — ย้ายฉบับที่ ๘ ลงเป็นก้อนตายตัว (ดึงข้อความจริงด้วย `git show HEAD:lib/prompt.js`) แล้วขึ้นฉบับที่ ๙ เป็น `CURRENT` ที่ดึงสดจาก `prompt.js` พร้อมเขียน `changes` / `why` / `effect` ครบ
🔑 **กฎเดิมของโปรเจกต์: แก้ prompt ต้องย้ายฉบับเดิมลง log ไม่งั้นหน้า "ประวัติคำสั่ง" ในเว็บประวัติขาดช่วง**

**เทสแล้ว** — โหลด `PROMPT_LOG` ได้ครบ 9 ฉบับ · `npm run build` ผ่าน
⏳ **ยังไม่ได้ยิงเทสกับโมเดลจริง** (เครื่องที่ทำงานไม่มีกุญแจ) — จดไว้ใน `docs/TODO.md` แล้วว่าต้องวัดในเวอร์ชัน 3

## เรื่องที่ 3 · ทดลอง M2 ซ่อมคำสกัดของคลังเดิม 394 คำ

**M2 คืออะไร** — ไอเดียที่พี่กันวางไว้ใน `roadmap.md` ตั้งแต่ 22 ก.ค. = AI **เจ้าเดียว** เรียกหลายรอบ แต่ละรอบสวมบทเอเจนต์คนละหน้าที่ (สกัด → จัดหมวด → ตรวจ)
ใน `idea.md` เขียนไว้ว่าเอเจนต์ขั้นจัดหมวด **"รับคำที่สกัดได้" ไม่ได้รับวลีตั้งต้น** = แยกตาโดยโครงสร้างอยู่แล้ว → พี่กันออกแบบถูกตั้งแต่ตอนนั้นโดยยังไม่รู้ว่าจะเจอปัญหานี้

M2 ถูกพักไว้เพราะในเว็บต้องยิงหลายรอบ = จ่ายหลายเท่า **แต่รอบซ่อมนี้ทำผ่านแคลร์ ไม่ผ่าน API = ทดลองฟรี**

### สิ่งที่พี่กันเคาะก่อนเริ่ม
| ข้อ | คำตอบพี่กัน |
|---|---|
| ทำคลังไหนก่อน | **คลังเดิมก่อน** (คำสกัด 394 คำ) |
| ความหมายเขียนแค่ไหน | **เฉพาะคำที่ตีความได้หลายทาง** |
| เจอกิ่งเดิมที่ผิด | **ย้าย/ถอนได้เลย ไม่ต้องถามทีละจุด** |
| ใครตรวจ | _"4 เธอตรวจแหละ"_ = **แคลร์ตรวจเอง ไม่ใช้เอเจนต์ตรวจ** |

### วิธีทำ

🔒 **หัวใจ: ไฟล์โจทย์มีแค่ 2 ช่อง `id` กับ `w` (ตัวคำ)** ห้ามมีวลีตั้งต้น ห้ามมีกิ่งเดิม ห้ามมีหมวดเดิม
เขียน `before.json` (กิ่ง/ความหมาย/วลีตั้งต้นเดิม) แยกไว้ต่างหาก **ไม่ส่งให้เอเจนต์**

เอเจนต์ **2 ตัว** (394 คำ ÷ ~330 ต่อตัว ตามสเกลที่พี่กันกำหนด) แต่ละตัวได้ฐานกิ่ง 768 กิ่งเต็ม
คืนมา 3 อย่างต่อคำ — `senses` (ความหมายที่เป็นไปได้ทั้งหมด) · `meaning` (เขียนเมื่อ senses > 1) · `paths` (กิ่ง 1–4 กิ่ง)

### ผลลัพธ์

| | |
|---|---|
| คำที่ทบทวน | 394 |
| **คำที่ตีความได้หลายทาง** | **122 คำ (31%)** |
| กิ่งที่เพิ่ม | **488 เส้น · 310 คำ** |
| กิ่งที่ถอนจริง | **4 เส้น** (จากที่เสนอ 88) |
| คำที่ได้ความหมายใหม่ | **72 คำ** |
| **คำสกัดที่ได้กิ่งเหมือนวลีตั้งต้นเป๊ะ** | **66 → 29 คำ (ลด 56%)** |

คลังเดิม 1,642 → **1,891 แถว** · เส้นเชื่อมคำ-กิ่ง 2,065 → **2,549** · กิ่งเท่าเดิม 768

### 🏆 ข้อค้นพบใหญ่ที่สุด — M2 ใช้ "เพิ่มกิ่ง" ได้ดีมาก แต่ใช้ "ถอนกิ่ง" ไม่ได้เลย

เอเจนต์ที่ไม่เห็นวลีตั้งต้น **มองไม่เห็นว่ากิ่งเดิมมีที่มาจากไหน** จึงเสนอถอนกิ่งที่ถูกต้องอยู่แล้วออก
แคลร์ตรวจเองทั้ง 88 เส้น **รับ 4 ปฏิเสธ 84**

ตัวอย่าง — `ปรก` ← `หนวดเคราปรกหน้ารุงรัง` (จะถอนกิ่งหนวดและเครา) · `ชุ่ม` ← `ชุ่มไปด้วยเหงื่อ` (จะถอนกิ่งเหงื่อ) · `แก๊ก` ← `เสียงดัง แก๊ก` (จะถอนกิ่งเสียงกระทบ)

🔑 **ตรงกับกฎเหล็กที่คลังมีอยู่แล้ว: "เพิ่มได้ ลดไม่ได้"** → **ถ้าเอา M2 เข้าเว็บ ต้องล็อกให้เพิ่มกิ่งได้อย่างเดียว ห้ามถอน**

🛡 **ถอนจริงเฉพาะกรณีปลอดภัยกรณีเดียว = ถอนกิ่งแม่ทั้งที่ยังเก็บกิ่งลูกไว้** (ละเอียดขึ้น ไม่มีข้อมูลหาย) — `ชันเข่า` · `สมส่วน` · `ส่องสว่าง` · `แมกไม้`

### 88 เส้นแยกได้ 7 กลุ่มตามกลไกที่ทำให้ผู้ช่วยพลาด

พี่กันสั่ง _"เอา 88 นั้นมาให้ดู อยากรู้ว่าทำไมเธอแย้ง และเอเจ้นทำไมให้ถอน เอา md มาเลยนะ เราว่าจุดนี้วิจัยต่อได้ และเราจะลองอ่านเอง"_

| กลุ่ม | กลไก | เส้น |
|---|---|---|
| ก | วลีตั้งต้นระบุ "ของจริง" ที่คำไปเกาะ (หนวดเครา · เหงื่อ · เงา · ดวงตา · เลือด) | 31 |
| ข | คำถูกใช้กับ "เสียง" แต่ผู้ช่วยตีความเป็นของทางกายภาพ | 15 |
| ค | ตัดความหมายเชิงเปรียบ/นามธรรมทิ้ง (ฝังแน่นในใจ · ลอยคว้างในความทรงจำ) | 14 |
| ง | ตัดมิติหนึ่งของตัวคำเองทิ้ง | 10 |
| จ | กิ่งที่เสนอละเอียดกว่า แต่กิ่งเดิมก็ไม่ผิด | 10 |

| ฉ | รับการถอน (ถอนกิ่งแม่ เก็บกิ่งลูก) | 4 |

### 🧠 ข้อค้นพบรองที่อาจสำคัญกว่าตัว M2 เอง

**กลุ่ม ง ชี้ว่าปัญหาอยู่ที่ "ขั้นเลือกกิ่ง" ไม่ใช่ "ขั้นเข้าใจคำ"**

หลายเส้นผู้ช่วย **เขียนความหมายไว้ถูกแล้ว แต่ตอนเลือกกิ่งกลับไม่เอาความหมายของตัวเองมาใช้**
- `บึ่ง` เขียนว่า "เร่งความเร็วพุ่งออกไป" → แต่ขอถอนกิ่งความเร็ว
- `ผุดลุก` เขียนว่า "ลุกพรวดขึ้นทันที" → แต่ขอถอนกิ่งความทันที
- `ปักหลัก` เขียนว่า "อยู่ที่ใดที่หนึ่งอย่างยาวนาน" → แต่ขอถอนกิ่งความยาวนาน

🎯 **ถ้าบังคับให้ไล่เลือกกิ่งทีละความหมาย อาจได้ผลใกล้เคียง M2 โดยไม่ต้องยิงหลายรอบเลย = ถูกกว่ามาก ควรลองก่อนตัดสินใจเอา M2 เข้าเว็บ**

### 🔵 4 เส้นที่แคลร์ไม่ฟันธง รอพี่กันเคาะ (กลุ่ม ช)

1. **`พลวัน`** ในวลี `รอยเท้าทับซ้อนพลวันกันไปมา` — ผู้ช่วยว่าแปลว่า "ทันทีทันใด" (มีในภาษาเก่าจริง) แต่ในวลีอ่านได้ว่า "เกลื่อนกลาดสับสน" · **ตอนเก็บคำ พี่กันตั้งใจให้แปลว่าอะไร** (2 เส้น)
2. **`เล่าลือ`** ควรอยู่หมวด 13 ภาษาด้วยไหม หรือเอาแค่กิ่งข่าวลือพอ
3. **`แหลมคม`** ควรอยู่กิ่งปากและฟันไหม (เผื่อเขี้ยวแหลม) หรือหลวมเกินไป

### 1 · ตัวเขียนที่ถอนชิปได้ ทำหมายเหตุขาดกลาง

- **แก้** — `split_chips()` ใน `apply_sense.py` แทนที่ ` · ` ที่อยู่ในวงเล็บหมายเหตุด้วยอักขระชั่วคราว `\x00` ก่อนตัด แล้วคืนกลับ
- **พิสูจน์** — ตรวจว่าชิปอื่นในบรรทัดเดียวกันไม่ถูกแตะ = 0 จุด

- **แก้** — ล้างวงเล็บออกจากความหมายด้วย `re.sub(r'\s*[()]\s*', ' ', mn)` ก่อนเขียนลงชิปเสมอ
- **พิสูจน์** — ป้าย/วงเล็บติดในตัวคำ = 0

   - **ขึ้น main เท่านั้น ทีเดียวจบ** ห้ามค้างบน branch ที่คลาวด์ตั้งให้
