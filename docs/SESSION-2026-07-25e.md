### ต้นเหตุ (2 ชั้นซ้อนกัน — ชั้นที่ 2 คือตัวฆ่า)
1. ช่อง "สกัดเอง" commit ค่า **เฉพาะตอนกด Enter** (`keydown` handler) — ข้อความที่พิมพ์ค้างในช่อง**ไม่เคยถูกเก็บลง state หรือ localStorage เลย**
2. `render()` ทำ `listEl.textContent=''` แล้ววาดแถวใหม่ทั้งหมด → **ทุกครั้งที่กด "แสดงเพิ่ม" / ค้นหา / เปลี่ยนตัวกรอง = ทำลาย `<input>` ทุกช่องที่ยังไม่กด Enter พร้อมกันทั้งหน้า**

### วิธีแก้ (อุดครบทุกทางที่ข้อมูลจะหลุด)
- `state.draft` — เก็บทุกตัวอักษรลง localStorage ทันทีที่พิมพ์ (debounce 140ms) + คืนค่ากลับตอนวาดแถวใหม่
- `commitAll()` กวาดเก็บทุกช่อง **ก่อน** `listEl.textContent=''` (เรียกบรรทัดแรกของ `render()`)
- commit เพิ่มอีก 4 ทาง: พิมพ์ `,` หรือขึ้นบรรทัดใหม่ / `blur` / ปุ่ม `＋ เพิ่ม` / `Enter`
- `flush()` ตอน `pagehide` + `beforeunload` + `visibilitychange` (สลับแอปบนมือถือ)
  เขียนทับ localStorage **เฉพาะตอนแท็บนี้มีของค้างจริง** (`if(n||saveT)`) กันแท็บที่ไม่ได้แตะอะไรไปทับของแท็บอื่น
- ส่งออกเรียก `commitAll()` + `commitPending()` ก่อนเสมอ

### กลไกสำคัญที่ต้องรู้ (ถ้าจะพอร์ตหรือแก้ต่อ)
- **ซอยคำไทย:** `Intl.Segmenter('th',{granularity:'word'})` ของเบราว์เซอร์เอง (ICU มี dictionary ไทย · Chrome/Safari ใช้ได้) → ลากแล้วหนึบเข้าขอบคำ ไม่ต้องเล็งทีละตัวอักษร · cache ใน `TOK` · fallback รายตัวอักษร
- **ลาก:** `pointerdown/pointermove` + `document.elementFromPoint` (รองรับทั้งนิ้วและเมาส์) · แตะคำเดียวไม่ลาก = เลือกคำนั้น
- **ล็อกจอ:** `.src{touch-action:none}` + `ev.preventDefault()` → ลากบนวลีแล้วจอไม่เลื่อน · **เลื่อนจอปัดที่ว่างนอกวลี** (จึงต้องเผื่อ `.list{gap:13px}` + padding การ์ด)
- **ป๊อป:** `#mag` เกาะ `src.getBoundingClientRect()` (ไม่ใช่พิกัดนิ้ว) + **ล็อกพิกัดไว้ใน `drag.mag` ตั้งแต่จังหวะแรก** → นิ่งสนิท · เนื้อหา = วลีเต็ม token ที่ลากถึง = `.mon` (สว่าง) ที่ยังไม่ถึง = `.mdim` (opacity .34)
- **หมายเหตุ 2 ระดับ:** รายคำ `state.wnote["บรรทัด|คำ"]` (เขียว เยื้อง `↳` โผล่ต่อท้ายคำ · แตะที่ตัวคำเพื่อเปิด) · ทั้งวลี `state.note[บรรทัด]` (ทอง เต็มความกว้าง `📝`)
- **ส่งออก:** TSV `คำ / วลีตั้งต้น / บรรทัด / ที่มา / หมายเหตุ` + ปุ่มคัดลอก + บันทึก JSON
- 🐛 **กับดัก CSS ที่เจอ 2 ครั้ง:** element ที่ตั้ง `display:` เองใน CSS **ต้องมี `[hidden]{display:none}` คู่เสมอ** ไม่งั้น `display:flex` ทับ `hidden` ของ UA stylesheet (เจอกับ `.selbar` แล้วไล่เพิ่มให้ `.addrow`/`.more`/`.notewrap`/`.wnotewrap`)
- 🐛 **media query ทับ clamp:** `@media(max-width:520px){.src{font-size:16px}}` ตกค้างจากเวอร์ชันแรก ทับ `clamp(22px,6vw,27px)` จนวลีไม่ใหญ่ขึ้นเลย — **ถ้าไม่เปิดเทสวัดค่าจริงจะไม่มีทางรู้ เพราะ CSS ไม่ error**
