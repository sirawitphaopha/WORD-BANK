## ๒ · หน้ารายละเอียดคำ — ผังใยความคิด

`components/pages/wordWeb.jsx` (ใหม่) · ยกม็อคอัปที่เจ้าของคลังเคาะมาทั้งชุด
(`docs/archive/misc/word-web-mockup.html` — ติมา 4 รอบกว่าจะลงตัว)

ตอบ ๔ คำถามที่เจ้าของคลังกำหนดตอนออกแบบ — แตกมาจากวลีไหน · หรือเก็บมาเอง · เจอเรื่องไหน · อยู่หมวดกิ่งไหน

### 🔒 สิ่งที่เจ้าของคลังสั่งว่าห้ามตัดออก

- คำสกัด **ระบายคนละสี** ในตัววลี (จานสีชุดเดียวกับหน้าตรวจทาน)
- **เส้นลากจากคำที่ระบายสี ไปหาชิปคำสีเดียวกัน**
- **กิ่งแยกไปหาหมวด แล้วหมวดแยกไปหากิ่งย่อยแบบ mind map**
- **คำหลักต้องเด่นชัด** กรอบหนา เงา ตัวใหญ่ ป้ายแดงชาด
- **เส้นต้องงอก** ไม่ใช่ขึ้นเต็มค้าง · **เส้นประต้องงอกเป็นประตั้งแต่แรก** (ทำด้วย SVG mask)
- 🚫 **ห้ามมีจุดวิ่งไปตามเส้น** — _"ไม่เอาแบบส่งสัญญาณประสาทแบบนี้ ไม่สวย"_

### 🔴 บทเรียนที่ยกมาจากม็อคอัพ ห้ามลืม

**วัดตำแหน่งด้วย `offsetLeft`/`offsetTop` ห้ามใช้ `getBoundingClientRect`**
การ์ดทุกใบมีแอนิเมชันลอยขึ้น (`transform: translateY + scale`) — `getBoundingClientRect`
บวกการขยับนั้นเข้ามาด้วย = วัดได้คนละค่าทุกเสี้ยววินาที ทำให้ระบบเข้าใจว่าเลย์เอาต์เปลี่ยน
แล้ววาดเส้นใหม่ทับ **เส้นที่กำลังงอกถูกรีเซ็ตกลางคัน ไม่มีใครเห็นตอนงอกเลย**

`offset*` มาจากการจัดหน้าล้วน ไม่นับ transform → นิ่งตั้งแต่เฟรมแรก

## ๓ · ช่อง `word_form` — คำนี้สร้างขึ้นมายังไง

เจ้าของคลังเสนอเองหลังคุยเรื่องคำซ้อน — _"คำซ้อน เราบอกว่าจะทำนี่นา เราทำแบบไหนดี ติดแท็กชนิดใช่ไหมนะ"_

### 🔑 ทำไมต้องเป็นช่องใหม่ ไม่ใช่ค่าใหม่ในช่อง `kind`

| ช่อง | ตอบคำถามว่า |
|---|---|
| `kind` | **ยาวแค่ไหน** — คำ / วลี / ประโยค |
| `word_form` | **สร้างยังไง** — คำซ้อน / คำซ้ำ / คำประสม / คำทับศัพท์ |

`หนั่นแน่น` เป็นทั้ง **คำ** และ **คำซ้อน** พร้อมกัน = คนละแกน
ถ้ายัดช่องเดียวกันต้องเลือกอย่างใดอย่างหนึ่ง แล้วเสียอีกอย่างไป

### สิ่งที่เจ้าของคลังเคาะ (3 เรื่อง)

1. **ค่าเดียวต่อคำ ปล่อยว่างได้** — ว่าง = ยังไม่ได้ดู ไม่ใช่ผิด
2. **4 ประเภท** ตัดคำมูลกับคำสมาสออก เพราะไม่ช่วยงานเขียนนิยาย
3. ทำ `word_form` ก่อนเว็บพรูฟ

### 🎯 ประโยชน์จริง — กันตัวตรวจคำผิดทักผิด

**คำซ้อนแบบไทยหน้าตาเหมือนคำพิมพ์ผิดมาก** ผู้ช่วยเคยติดธง `หนั่นแน่น` ว่าสะกดผิด
ทั้งที่ `หนั่น` มีในพจนานุกรมราชบัณฑิตยสถานแปลว่าแน่น (ใช้ว่า "เนื้อหนั่น")

### 🔴 เครื่องจับเองไม่ได้ ต้องให้ AI เติม

ทดลองเขียนตัวจับรูปแบบคำซ้อนด้วยเครื่องล้วน (พยัญชนะต้นซ้ำ) จับได้ 636 คำ
**แต่ผิดเกินครึ่ง** เพราะภาษาไทยไม่มีช่องว่างระหว่างคำ มันซอยคำผิด

```
กรอกตา      → กรอ + กตา       ✗ ที่จริงคือ กรอก + ตา (ไม่ใช่คำซ้อน)
กระดากอาย   → กระดา + กอาย    ✗ ที่จริงคือ กระดาก + อาย
กระฉับกระเฉง → กระฉับ + กระเฉง  ✓ อันนี้ถูก
```

→ **กฎข้อ 4ก ใน `lib/prompt.js`** ให้ AI เติมตอนจัดคำ · เจ้าของคลังแก้เองได้ในหน้าต่างแก้ไข
→ **SQL เติมย้อนหลังแค่ 2 กรณีที่เป็นกฎตายตัว** — ลงท้ายไม้ยมก = คำซ้ำ · หมวด 7 = คำทับศัพท์

### 🐛 บั๊กที่เจอ — backtick ในข้อความทำ build พัง

`lib/prompt.js` ทั้งก้อนเป็น **template literal ครอบด้วย backtick**
พอใส่ `` `หนั่นแน่น` `` เป็นตัวอย่างในกฎ มันไปปิดสตริงกลางคัน build พังทันที
**แก้: ใช้เครื่องหมายคำพูดแทน backtick เสมอในข้อความ prompt**

### ตัวกรองในหน้าคลังคำ

ดรอปดาวน์ "รูปแบบคำ" ทั้ง 2 จอ · มีตัวเลือก **"ยังไม่ได้ระบุ"**
ไว้ไล่เติมทีละคำ — ซึ่งเป็นเหตุผลที่เจ้าของคลังอยากได้ช่องนี้ตั้งแต่แรก
> _"ระบบธงสงสัยนี่ดีนะ เพราะมันกรองเอามาดูได้"_

### ประวัติคำสั่งไม่ขาดช่วง

ย้ายคำสั่ง AI ฉบับก่อนแก้ลง `lib/promptlog.js` เป็น **ฉบับที่ ๖** แล้ว
