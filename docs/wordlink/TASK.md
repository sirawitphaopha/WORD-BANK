# โจทย์ · ตรวจสอบเส้นโยง "คำเดี่ยว ↔ วลี" ในคลังคำ

## สิ่งที่ต้องทำ

ไฟล์โจทย์มีคู่ **คำเดี่ยว** กับ **วลี** ที่คำนั้นปรากฏอยู่ข้างในวลี แต่ยังไม่มีเส้นโยงถึงกันในคลัง
งานของคุณคือตัดสินทีละคู่ว่า **คำนั้น "ถูกตัดออกมาจากวลีนี้" หรือ "เก็บมาต่างหาก แล้วบังเอิญไปปรากฏร่วมกัน"**

## บริบทที่ต้องเข้าใจก่อน

เจ้าของคลังเป็นนักเขียนนิยาย เก็บคำงามจากนิยายที่อ่าน โดยพิมพ์ลงไฟล์ทีละบรรทัด
เจ้าของคลังเล่าเองว่า **"บางวลีเราแตกเองตอนจด"** — คือจดวลียาวไว้ก่อน แล้วแตกคำเด่นออกมาจดต่อในบรรทัดถัดไปทันที
แต่บางคำก็เก็บมาต่างหากจริง ๆ คนละครั้งคนละที่

**เกณฑ์ที่เจ้าของคลังกำหนดเอง**
1. **อยู่คนละเล่ม → เก็บแยกแน่นอน** ไม่ได้ตัดมาจากวลีนั้น
2. **จดติดกันหรือใกล้กันในไฟล์ต้นฉบับ → ตัดมาจากกันแน่นอน**
3. **จดห่างกันมาก (เช่นบรรทัด 20 กับบรรทัด 300) → เก็บแยก**

## ช่องข้อมูลในไฟล์โจทย์

| ช่อง | คือ |
|---|---|
| `n` | เลขข้อ (ห้ามเปลี่ยน ต้องส่งกลับมาด้วย) |
| `word` | คำเดี่ยว |
| `phrase` | วลีที่คำนั้นปรากฏอยู่ข้างใน |
| `word_novel` · `phrase_novel` | ชื่อนิยายที่เก็บมา |
| `word_line` · `phrase_line` | เลขบรรทัดในไฟล์ต้นฉบับ (`null` = หาไม่เจอ) |
| `gap` | ระยะห่างของบรรทัด (ถ้ามี) |
| `word_meaning` | ความหมายที่บันทึกไว้ |
| `group` | กลุ่มที่เครื่องจัดให้เบื้องต้น — **คุณมีหน้าที่ตรวจว่าถูกไหม** |

## สิ่งที่ต้องส่งกลับ — เขียนลงไฟล์ผลลัพธ์ทีละ 40 ข้อ ห้ามรอเขียนทีเดียวตอนจบ

รูปแบบ JSON Lines หนึ่งบรรทัดต่อหนึ่งข้อ

```
{"n": 12, "verdict": "ตัดมา", "confidence": "สูง", "why": "จดติดกันบรรทัด 315-316 และคำมีความหมายตรงกับส่วนหนึ่งของวลี"}
```

**ค่า `verdict` มี 4 ค่า**

| ค่า | ใช้เมื่อ |
|---|---|
| `ตัดมา` | คำถูกตัดออกมาจากวลีนี้ |
| `เก็บแยก` | คำเก็บมาต่างหาก บังเอิญปรากฏร่วมกัน |
| `ไม่แน่ใจ` | หลักฐานไม่พอตัดสิน |
| `ไม่เกี่ยวกัน` | **คำไปโผล่ในวลีโดยบังเอิญเชิงตัวอักษร ไม่ได้เกี่ยวกันเชิงความหมายเลย** — เช่นคำหนึ่งเป็นแค่ส่วนหนึ่งของอีกคำที่ยาวกว่าและคนละความหมาย · เส้นแบบนี้ไม่ควรโยงเลย |

`confidence` = `สูง` / `กลาง` / `ต่ำ`
`why` = เหตุผลสั้น ๆ ภาษาไทย 1 ประโยค **ต้องอ้างหลักฐานจริง** (เลขบรรทัด · ชื่อเล่ม · ไฟล์ picked · ความหมาย) ห้ามเขียนลอย ๆ

## กฎ

1. **ห้ามแก้ไขไฟล์ในคลังเด็ดขาด** งานนี้อ่านอย่างเดียว เขียนได้เฉพาะไฟล์ผลลัพธ์ของตัวเอง
2. **ห้ามข้ามข้อ** ต้องมีคำตอบครบทุก `n` ที่ได้รับ
3. **ห้ามเปลี่ยนตัวข้อความของ `word` หรือ `phrase`** ส่งกลับมาแค่เลข `n`
4. อย่าเชื่อช่อง `group` ที่เครื่องจัดมาให้ — **ตรวจเองทุกข้อ** ถ้าไม่เห็นด้วยให้ตอบต่างได้ แล้วบอกเหตุผล
5. เครื่องมือในเครื่องนี้ **ไม่มี Python** ให้ใช้ Node หรืออ่านไฟล์ตรง ๆ
